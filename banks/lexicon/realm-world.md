# 异界 · 末世世界词库

> 来源：E:\fanqie\TXT 网文全书扫描提炼（异界部落/领主/种田/重生 + 末世/无限流/进化）。
> 定位：异界世界构建——部落/领地/种田/建设/资源；末世场景——废土/副本/变异/进化/系统面板。填补「世界建设」维度。
> 写法要点：世界感靠「细节堆」——部落的篝火兽皮、领地的城墙人口、末世的废土物资。词条提供世界场景的可复用描写。
> 标签：`[通用]` / `[古风]` / `[都市]`。`⚠` = 反 AI 冲突词。

（异界部落 · 兽人 · 种田 · 物资 · 领地）

- **兽娘 / 兽耳娘** — 兽人少女，耳尾保留兽类的异世界设定锚点，出场即吸睛。[古风]
  例句：他身边围着一圈兽娘，猫耳的、狐尾的，个个眼睛亮晶晶地盯着他手里的食物。
  提示：写"兽耳＋尾巴＋个性"三件套立人设；耳尾反应当情绪信号（竖/垂/颤）。

- **部落** — 异世界最小社会单元，以血缘/神巫为纽带的聚居群体，全书叙事单位。[古风]
  例句：荒原上的部落多以狩猎为生，没有巫的部落连火都借不来。
  提示：部落→小镇→城池→帝国是发展线，每升一档就是一章的爽点。

- **巫** — 部落精神领袖兼施术者，会巫术/能沟通神谕，地位常在首领之上。[古风]
  例句：整个部落都靠这位老巫撑着，她一句话就能定下迁徙还是留守。
  提示：巫＝部落的希望象征，失去巫＝失去火种（设定句，可作剧情发动机）。

- **神巫** — 能与天神沟通、求得神赐之物的高阶巫，超大型部落才有的排面。[古风]
  例句：能沟通天神、求得神赐之物的神巫，是那些超大型部落才有的招牌。

- **觉醒战士** — 部落战斗核心，靠觉醒获得超常力量，是"巫之下第一重要"的武力位。[古风]
  例句：一个部落能有一两个觉醒战士，就够在荒原上站稳脚跟了。
  提示：写"觉醒"配额头符文/力量外放，与 xianxia 突破语感嫁接。

- **巫药** — 巫调配的药，部落间的硬通货，常作交换物资。[古风]
  例句：流浪者拿不出值钱东西，只想用巫药和咸石换一点盐回去。
  提示：写部落交易戏，巫药/咸石/兽皮是通用"货币"。

- **神赐之物** — 传说天神丢下的宝贝，部落争夺、远行者寻找的目标。[古风]
  例句：为了一件神赐之物，两个部落能在雪原上对峙好几年。

- **献祭 / 祭天** — 向天神供奉物品换庇护/奖励的部落仪式，信仰与钩子兼备。[古风]
  例句：部落把最好的猎物献祭给天神，求一个不冻死人的冬天。
  提示：系统流可借"祭天"包装金手指——遇事不决，神学解决。

- **借火** — 部落间借火种的人情往来，没巫的部落低人一等的具象。[古风]
  例句：没有巫的部落，连借火都得看有巫部落的脸色。

- **流浪者** — 失去巫/家园的部落残部，居无定所、任人欺凌，惨况即收留动机。[古风]
  例句：没有巫的部落就是流浪者，走到哪儿都抬不起头。

- **族人** — 部落成员统称，写集体归属感与责任感。[古风]
  例句：为救那几个被掳走的族人，他愿意拿命去换。

- **首领 / 狩猎首领** — 部落行政与战斗指挥，与巫分工制衡；狩猎首领=武力标杆。[古风]
  例句：狩猎首领是部落最能打的那个，巫则是部落最能说话的那个。
  提示：写"首领信服主角/被主角取代"是部落戏的权力爽点。

- **狩猎** — 部落主要谋生方式，侦察→围杀→剥皮分肉构成日常叙事。[古风]
  例句：这一趟狩猎带回来两头牦兽，够部落吃上大半个月。

- **兽皮 / 兽皮裙** — 蛮荒服饰与物资主力，裹身、铺床、交易皆可。[古风]
  例句：兽皮裙上沾着雪和腥味，那是兽娘们最体面的衣裳。
  提示：写蛮荒生存用"兽皮＋骨制＋茅草"三件套立服饰感。

- **雪屋（雪砖）** — 极地生存建筑，切雪砖/垒圆屋/留洞口一套流程，求生爽点核心。[古风]
  例句：把压实的雪切成四四方方的雪砖，一块块垒成半圆，一座雪屋就立了起来。
  提示：写"从无到有搭起庇护所"，配切砖/搬运/加固的分镜头。

- **营地** — 部落歇脚扎寨的据点，篝火是营地的中心与归返信号。[古风]
  例句：营地的篝火一亮，散出去的猎人就知道该回来了。

- **山洞（庇护所）** — 荒原上最稀缺的栖身地，找到山洞＝安全感到手。[古风]
  例句：大雪原上走了三天，能找到一个背风的山洞，比捡到宝还高兴。
  提示：迁徙戏里"山洞/雪屋/木屋"三档住房＝发展刻度。

- **木屋** — 比雪屋高级的定居建筑，部落由"躲"转"住"的标志。[古风]
  例句：等部落会搭木屋了，就不再是东躲西藏的流浪者了。

- **制陶 / 陶器** — 种田/文明线关键技能，从泥到罐的成就感，教技能比直接给成品更爽。[古风]
  例句：教她们用黏土烧出第一个陶罐时，那点泥腥味都变成了宝贝味。
  提示：写"教异世界原住民文明技能"是种田文的格局爽点。

- **耕种 / 种田** — 部落摆脱打猎为生的转向，食物自给的里程碑。[古风]
  例句：第一茬作物抽芽那天，整个部落都蹲在地边看稀罕。

- **驯养** — 收服野兽当坐骑/帮手，部落实力的活招牌。[古风]
  例句：把最凶的雪狼驯成看家的狗，这事儿够部落吹三年。
  提示：写驯服过程：对峙→喂食→认主，一步步来才有征服感。

- **传送法阵** — 跨地图的高阶建设，领地扩张的关键设施。[古风]
  例句：两座城之间的传送法阵一立，原本要走半个月的路，眨眼就到。

- **明石** — 发光又能致病的特殊矿石，部落对它的态度分裂成两派。[古风]
  例句：有人拿明石当宝贝，有人把它当灾祸之石，部落为此分成了两拨人。
  提示：写"好东西有代价"的资源设定，制造阵营矛盾。

- **咸石 / 盐** — 蛮荒硬通货，缺盐＝缺命，交易戏常用。[古风]
  例句：一块咸石能换三张兽皮，在荒原上盐比命金贵。
  提示：写"以物易物"给出汇率感，数字即氛围。

- **储物项链** — 空间道具，随身金库，配"滴血/魔力沟通"开箱的仪式感。[古风]
  例句：他把物资全塞进储物项链，两手空空地混进城里，半点风声不露。

- **领地** — 部落扎根的地盘，从"栖身地"到"经营范围"的进阶。[古风]
  例句：这块领地背靠雪山、面朝冰湖，种田狩猎都方便，谁见了都眼红。

- **小镇 / 城池** — 部落发育成定居点的形态，名字一取就有归属感。[古风]
  例句：当初那个挤在山洞里的小部落，如今发展成了一座像模像样的小镇。
  提示：写发展史用"部落→小镇→城池→帝国"的量级跃迁。

- **围坐议事** — 部落决策的集体场景，盘坐成一圈、火堆为心，几句交代一场会。[古风]
  例句：火堆旁，族人们盘坐成一圈，等首领发话。

- **物资 / 口粮盘点** — 部落生存命脉，清点即危机感来源，把穷具象成数字和物件。[通用]
  例句：清点完剩下的口粮，每个人脸上的表情都沉了下去。
  提示：写"盘点"制造紧张或踏实，列表越具体越好。

- **木柴 / 燃料** — 生存资源之一，捡柴砍树是日常支线，也是危机伏笔。[古风]
  例句：天没黑就把柴火备足，夜里雪屋才敢烧火。

- **骨刀 / 骨矛（原始武器）** — 石器时代装备，对比现代工具/铁器显文明代差。[古风]
  例句：那把磨得发亮的骨刀，在铁斧面前脆得像树枝。
  提示：写"旧装备 vs 新装备"的对比是种田文进步感的来源。

- **温泉 / 冰湖** — 荒原上的自然资源点，泡温泉是难得的享受戏，冰湖可猎鱼。[古风]
  例句：雪原深处的温泉冒着热气，泡进去的那一瞬，骨头都酥了。

- **雪狼 / 牦兽（雪原野兽）** — 雪原生态的野兽，狩猎、驯养、命名皆素材。[古风]
  例句：雪原上最值钱的猎物是雪绒牦兽，一头能换一整个冬天的柴火。

- **首领大人 / 巫大人** — 部落对首领/巫的尊称，等级感的语言外壳。[古风]
  例句："首领大人"三个字一出口，围过来的族人自动让开一条道。
  提示：称谓＋汇报内容组合，是部落群戏的标配对白。

- **苦寒之地（荒雪原）** — 生存艰难的地域底色，写困顿与求生欲的出发点。[古风]
  例句：荒雪原上活下去的本事，是一代代人拿命试出来的。

- **无巫＝流浪者（设定句）** — 部落世界观的底层规则，一句交代地位等级。[古风]
  例句：在这个世界，没有巫的部落就是流浪者，连一块落脚地都守不住。
  提示：写"巫＝部落命根"的设定，推动抢巫/请巫/信巫的情节。

- **部落归属（战败并入）** — 战败并族、投靠结盟的部落关系戏。[古风]
  例句：战败的部落并入胜者的族谱，从此改姓易名，跟着新首领过活。

- **贵部落（敬语）** — 部落间打交道的客气外壳，一句定礼数。[古风]
  例句："贵部落肯借盐，这份人情我们记下了。"

- **值守 / 瞭望** — 部落守备，写危机感与营地日常。[古风]
  例句：洞口留了两个值守的，剩下的人这才敢合眼睡上一觉。

- **肉干储备** — 食物储备，写"攒下来"的踏实与过冬底气。[古风]
  例句：洞顶挂着一排肉干，那是整个部落过冬的底气。

## 网文补充（异种族大领主 提炼）

（领主 / 领地 / 建设 / 兵种 / 种族 / 争霸 / 城池）

- **建立领地（打下第一块地盘）** — 领主文的起步爽点：从孤身一人到拥有第一个落脚点，之后一切建设都从这里长出。[古风]
  例句：他在林间扎下营地，插上旗子，宣布这里就是自己的领地。
  提示：配"收拢第一批人手→修第一道墙→挂第一块招牌"，领地感一步步立起来。

- **领地** — 主角的地盘统称，领主文一切目标都指向"守住它、扩大它"。[古风]
  例句：这座小镇连同周围的山林，如今都是他的领地。
  提示：写"领地又扩张了 / 领地遭袭 / 领地人来人往"三条线轮换。

- **领主** — 一方地盘的最高话事人，从被使唤到发号施令的身份跃迁。[古风]
  例句：从流亡者到一方领主，他用了不过三年。

- **领主大人（领民的称呼）** — 身份转变的听觉信号：称呼一变，地位立现。[古风]
  例句：街上的行人纷纷停下行礼："领主大人。"
  提示：写主角"第一次被人叫领主大人"的瞬间，爽感比打一场架还足。

- **领民** — 领主治下的人口，"人即资源"的直观体现。[古风]
  例句：领民越聚越多，粮食的压力也跟着涨了上来。
  提示：领民 = 兵源 + 劳动力 + 税收，写"收留难民"就是在扩地盘。

- **收拢各族，为我所用** — 领主文核心玩法：把不同种族的力量都变成自己阵营的。[古风]
  例句：会种地的归你，会打铁的归你，会射箭的也归你——各族各有各的用处。
  提示：写"各取所长分配岗位"比写"招了很多人"有画面。

- **种族天赋（各族自带特长）** — 设定宣讲句式：一句把各族能力拉清单，世界观立住。[古风]
  例句：人族的斗气、兽人族的兽化、精灵族的射术、矮人族不灭的肉体、龙族的龙息，各有各的强。
  提示：写"凭什么要拉拢这个种族"时用，特长 = 价值的直接理由。

- **以XX之神的名义发誓** — 异界最高誓言，比"我发誓"重一个量级。[古风]
  例句：我以兽人之神的名义发誓，绝不放过你。
  提示：异族起誓专用；写"用神名义撒谎"被拆穿，是制造信任危机的钩子。

- **各族摩擦不断，战争时有发生** — 异界乱世的背景板，一句定调"不和平"。[古风]
  例句：这片大陆上各族摩擦不断，今天你打我，明天我抢你。
  提示：用来解释"为什么需要强权 / 为什么主角的融合事业有意义"。

- **强者为尊** — 异界底层逻辑：拳头大就是规矩。[古风]
  例句：道理在这片大陆上不值钱，强者为尊。
  提示：写在主角"被人敬 / 被人欺"之前，先立规则再写爽点。

- **四大帝国各据一方（大陆版图句式）** — 开局交代世界地图的固定句式，东南西北各一族。[古风]
  例句：人族帝国在东，精灵帝国在西，矮人帝国在南，兽人帝国在北，海族则把持着所有海域。
  提示：地图 = 势力分布图，之后所有"去哪个方向"都有指向性。

- **四战之地（多族交界处）** — 各族势力交界的真空地带，乱但有机遇。[古风]
  例句：这地方正处在四大帝国的交界处，谁也管不着，三教九流都往这里钻。
  提示：写主角"开局捡漏"的舞台；交界的乱 = 机会多。

- **临时聚集地（三不管的边境小镇）** — 起于利益、散于战乱的松散聚落，领主文前期大本营的雏形。[古风]
  例句：说是镇子，其实只是几伙生意人图方便凑出来的临时聚集地。
  提示：写"聚集地→正式领地"的升级线，从"没人管"到"归我管"。

- **魔兽横行的野外** — 出城即危险的世界设定，普通人不敢在夜间逗留。[古风]
  例句：一到天黑，魔兽就格外活跃，没有人会蠢到这时候还留在林子里。
  提示：写"主角赶夜路 = 玩命"的紧张感；也解释"领地为什么需要城墙和巡逻"。

- **魔核** — 魔兽体内的魔力核心，异界硬通货：修炼、换钱、锻器全靠它。[古风]
  例句：魔核是魔兽一身的精华，也是猎人们最想从尸体上扒下来的东西。
  提示：写"猎兽取核"的经济线，等级越高的魔核越值钱。

- **魔兽皮毛 / 战利品清点** — 猎兽后的资源清单，前期脱贫的主要来源。[通用]
  例句：他剥下那几块魔兽皮毛，盘算着能换多少盐。
  提示：写"战利品清点"是种田流固定爽点，数量 + 成色都给出来。

- **空间戒指** — 异界版储物袋，随身仓库，领主外出的标配。[古风]
  例句：他随手从空间戒指里取出那袋盐。
  提示：与仙侠"储物袋"对应，异界西幻味靠它立住；"空间戒指被夺 / 装不下"是冲突点。

- **佣兵公会** — 异界的情报与交易中枢：接活、买魔核、打听消息都在这。[古风]
  例句：只要是想赚钱的武者，几乎都绕不开佣兵公会。
  提示：写"进公会看悬赏 / 打听消息"的信息集散地功能。

- **奴隶市场 / 捕奴团** — 异界黑暗经济：战俘、落难者被明码标价，主角救人或抢人都从这下手。[古风]
  例句：捕奴团常年在这片边境转悠，专挑落单的异族下手。
  提示：写"买奴→放奴→收人心"是异界领主文收人手的固定捷径。

- **禁锢项圈** — 压制奴隶能力的项圈，囚奴戏的关键道具。[古风]
  例句：为防止奴隶逃跑，商人们会给他们戴上禁锢项圈。
  提示：写"拆项圈 = 放自由"的一刻，恩义就此结下。

- **硬通货（盐 / 粮食 / 酒）** — 战乱期货币不稳，实物才是硬通货，主角垄断特产的致富路。[古风]

  例句：圆月升起，老祭司的手指沾了血，在少年胸口划过一道利爪印，四周的族人齐齐嚎叫起来。

- **兽化失败被驱逐** — 无法兽化＝没有狩猎能力，被逐出族群丢进凶兽纵横的荒野。部落法则的残酷面。[古风]
  例句：没能获得返祖之力的少年被赶出领地边缘，族人盯着他离开，有生之年不许他再踏进一步。
  提示：写"法则无亲情"——族长的儿子也保不住，规则越重，后续收留流亡者的爽点越大。

- **圣兽 / 图腾信仰** — 部族供养圣兽、膜拜图腾石像，圣兽走丢、供奉中断都是部落大事件。原始信仰体系。[古风]
  例句：圣兽走丢的消息传开，全族的祭司倾巢出动，沿祖山的方向一路找过去。
  提示：圣兽可当"部落祥瑞/政治筹码"，走丢正好引出寻宝、结盟类支线。

- **大祭司 / 大司命体系** — 族群权力双轨：能兽化的族长管狩猎武力，祭司管仪式占卜，大司命的"名头"就能压人一头。部落政治结构。[古风]
  例句：他报出青牛大祭司派来谈交换的名号，光这一句，沿途部落都给他让了路。
  提示：名头＝剧情通行证，祭司线是"面子政治"的引擎，谈判戏全靠它抬身价。

- **双形态（人形 / 兽化）** — 平时人形生活、战时兽化搏杀，兽耳世界的基础设定，也是战力展示的口子。[古风]
  例句：他一路都维持着人形，直到狼群合围上来，才猛地兽化，身形拔高了整整一截。
  提示：兽化是"变身镜头"，配合体型暴涨+嘶吼写压迫；别每场打斗都兽化，留作底牌。

- **兽化次数限制** — 一天兽化不超过三次、有时限，战力是稀缺资源要省着用。战斗平衡设定。[古风]
  例句：兽化每日都有时限，他得盘算着哪一刻变身最值，变早了今天就没有第二次。
  提示：给战力上"预算"，打戏才有取舍，逼主角动脑子而非无脑莽。

- **原兽（兽耳人的猎物）** — 未进化出人形的野兽，体型比地球同种大一圈，既是猎场也是威胁源。[古风]
  例句：这世界的原兽都比想象中大，一头荒野鹿就有骆驼那么高，还带着鹿群首领的凶角。
  提示：写"猎物更大更凶"＝狩猎难度直接拉满，衬托主角技术流打法。

- **"只吃原兽，不吃兽耳人"** — 主角立规矩：吃肉只打原兽，不碰有智慧的兽耳人。设定亮点＋人格底色。[古风]
  例句："不用怕，我只吃原兽，不吃兽耳人。"他把手里的石矛往旁边一插，转身去生火了。
  提示：一句话同时立"安全承诺"和"底线人设"，是收服异族信任的起手式。

- **领地意识（不踏他族领地）** — 各族划地为界，不轻易踏足对方地盘，踩线＝开战。地图冲突引擎。[古风]
  例句：那片丛林是熊耳族的领地，他没招惹对方的本事，只能远远绕着走。
  提示：领地边界＝剧情传送门，写"越界→遭遇→结盟/开战"的固定循环。

- **部落联盟 / 多族联合** — 北方小族抱团抗敌、弱者依附强者，部落变联盟、联盟变国。领地扩张主线。[古风]
  例句：北面几十个小部落联合起来，推举了首领，一支新的联盟就这么立了起来。
  提示：扩张阶段写"人口少是短板"，联盟/收编要配"消化"过程，别一夜之间建国。

- **收编流亡族群** — 收留逃难、不能兽化、被驱逐的流亡者，人口暴涨，部落从几户变上百人。[古风]
  例句：逃难来的小族群在墙外站了一排，族长一句话，他们就拖家带口住进了部落。
  提示：收编＝人口爽点，但每收一拨都要写"分工/口粮/房子"的成本，种田感才真实。

- **人口增长 / 粮食焦虑** — 种田文的时间线压力：人口一年比一年多，农业跟不上就要饿死人。[古风]
  例句：再过几年人口翻倍，猎物和野菜都不够分，粮食要是种不出来，一场小旱就得饿肚子。
  提示：把"发展焦虑"挂在明处，就是读者追更的引擎；配"开荒/育种/储粮"的具体对策。

- **秋冬储粮过冬** — 秋天拼命囤肉、熏干、抹盐，为冬天储备食物，种田文循环节拍。[古风]
  例句：松木材的烟熏肉一批批挂上梁，抹了细盐，这是部落过冬的紧急储备。
  提示：储粮是"安稳→危机"的伏笔开关，缺粮夜袭/大雪封山都靠它引线。

### 兽耳娘（轻松流主输出）

- **毛茸茸的兽耳（竖起 / 耷拉 / 一抖）** — 兽耳娘情绪外露的器官：警戒竖起、委屈耷拉、被摸轻轻一抖。兽耳元素核心。[古风]
  例句：她脑袋上那对毛茸茸的长耳朵一竖，又很快耷拉下去，委屈全写在这对耳朵上了。
  提示：用耳朵代替表情写情绪，比"她很委屈"生动十倍；也是摸头杀剧情的现成道具。

- **兽尾（小短尾 / 受惊蜷起）** — 兽耳娘的尾巴细节，受惊卷进腿间、被捏会炸毛。身体语言补充。[古风]
  例句：他刚碰到她尾巴根，那根小短尾巴"嗖"地卷进腿间，她回过头警惕地瞪着他。
  提示：尾巴写"控制不住"，越是傲娇的角色越靠尾巴漏底。

- **圆红眸 / 小眼珠子转（兽娘眼）** — 兽耳娘的眼睛保留兽性：圆红眸、竖瞳，盯猎物时瞳孔收紧。兽与人的融合感。[古风]
  例句：溪水边蹲着个瘦小的兽耳少女，一对圆红眸死死盯着水面，小眼珠子不停地转。
  提示：兽娘眼睛是"萌＋野"的结合点，写戒备时瞳孔收紧、写撒娇时眼睛发亮。

- **犬齿 / 利爪（兽化形态）** — 兽化后犬齿外翻、利爪如刀，原始武装自带。写威慑与冲突。[古风]
  例句：他兽化的一瞬，犬齿从唇角翻了出来，利爪在地上刮出几道深痕。
  提示：写"武装漏出"比报实力更有压迫，配合低吼、体型暴涨成套使用。

- **竹叶裙 / 草裙 / 兽皮衣** — 原始衣装记忆点：竹叶编的短裙、草裙、胸口缠一圈兽皮。从裸到衣的文明萌点。[古风]
  例句：少女下身围着一条竹叶编的短裙，腰间挂着串骨珠，光着脚丫走起路来簌簌响。
  提示：服饰写"就地取材"，既是世界观细节，也是"文明进步"的进度条（草裙→麻衣→锦袍）。

- **捡来的兽耳娘（戒备→贴上来）** — 开局捡到无家可归的兽耳娘：先戒备缩角落、被投喂后眼神发亮、从此黏上主角。轻松流收后宫标准节奏。[古风]
  例句：那小家伙一开始缩在角落不敢动，叼走他递的肉之后，第二天就蹲在他洞口等开饭了。
  提示：先给"猎物/天敌"的惊吓戏，再转"认主"的甜，反差出轻松感；每个新角色走一套。

- **"她们自己就贴过来了"式嘴硬** — 主角嘴上否认"不是为了收集兽耳娘"，实际上兽耳娘一个接一个住进来。轻松向自嘲定调。[古风]
  例句：他叹着气解释，真不是想收集兽耳娘，是她们自己一个接一个住进部落的，赶都赶不走。
  提示：男主"口嫌体正直"＋女主们"主动上门"双向发力，是后宫流轻松感的核心公式。

- **给捡来的兽耳娘起名（认主）** — 起名＝接纳＝成为自己人，兽耳娘以名认主，收服仪式。[古风]
  例句：她仰着头让他起名，他想了想："就叫你小月吧。"她的眼睛一下子亮了。
  提示：起名戏＝关系破冰点，配"眼睛发亮/耳朵竖起"的反馈，收服感瞬间拉满。

- **同病相怜的收留** — 被驱逐者互相收留：同为兽化失败的流亡者，主动拉新人进洞穴、帮他安家。部落人情暖点。[古风]
  例句：两个同样没能返祖的少女走过来，拉着新来的人，帮他挑了一处朝南的洞穴。
  提示：写"同类相认"的细节（递食物/让位置），比大道理更有部落温度。

### 生存技能（种田开荒）

- **钻木取火** — 手搓木弓拉木棍、白烟、火星、轻吹，火光腾起的瞬间＝文明开端的里程碑镜头。[古风]
  例句：他压着心中的激动继续轻吹，火星肉眼可见地变多，昏暗的山洞里终于亮起一道火光。
  提示：写"搓—冒烟—吹—火起"四拍，别一笔带过，这是种田文第一个小高潮。

- **打磨石矛 / 石斧** — 敲石成刃、树皮绳绑缚，第一把武器/工具的诞生。[古风]
  例句：他用石片反复刮磨了两日，总算磨出一根勉强像样的矛头，拿树皮绳绑实了。
  提示：写"磨"的笨拙与认真＝原始人改造自然的实感；每造一件新工具就是一个小爽点。

- **藤编竹编（背篓 / 鱼笼 / 草鞋）** — 就地取材编容器：背篓装药材、鱼笼捕鱼、草鞋护脚。技术树分支。[古风]
  例句：她蹲在一旁看他搓树皮绳、编背篓，眼睛亮晶晶的，看得入了神。
  提示：手工技能写"实用＋被围观惊叹"，带出主角现代知识碾压原始世界的爽感。

- **设陷阱捕猎** — 挖坑、设网、放诱饵，次日去看，陷阱里躺着一只倒霉的猎物。种田文日常小爽点。[古风]
  例句：好在最后一个陷阱没让他失望，里面躺着一只倒霉的小兽，够他们今天加餐了。
  提示：陷阱戏主打"意外收获"，比正面狩猎省笔墨，适合日常过渡章。

- **耐力拖死猎物** — 原始人狩猎靠耐力：刺伤猎物一路吊着追，活活把它拖垮。以弱胜强的狩猎智慧。[古风]
  例句：原始猎人大多这么干——长矛刺伤猎物，就远远吊着追，直到它自己脱力倒下。
  提示：把"打不过"写成"追死它"，既合理又写出原始狩猎的野性智慧。

- **驯化圈养** — 抓野母羊配种、折翅圈养野鸡，从猎人到牧人的转变，食物自给线。[古风]
  例句：他们抓了几只野母羊回来圈养，部落从此有了自己的肉食来源，不用天天看天吃饭。
  提示：驯化是"稳定→扩张"的转折点，配"幼崽出生/下蛋"的小惊喜写日常甜。

- **烧陶 / 制盐 / 炼青铜** — 黏土烧陶罐、晒盐熬盐、煅铜矿铸器，技术升级三件套，种田文主线推进器。[古风]
  例句：第一批陶罐烧出来那天，族长抱着一个罐子，比打赢一场仗还高兴。
  提示：每突破一项技术＝一个小高潮，接"分配/炫耀/拿去换资源"落地，别停在"造出来"。

- **草木灰鞣制兽皮** — 石刀刮皮内侧、草木灰泡、火边烘烤，粗制毛皮的制作流程。[古风]
  例句：他把狐狸皮内侧刮干净，用草木灰泡了一夜，烘干了，就是一条能过冬的粗毛皮。
  提示：写"处理猎物"的工序＝狩猎回来的真实延续，种田文的"收入明细"。

### 建设与发展

- **砍竹围墙 / 建哨塔** — 砍竹扎墙、四角立哨塔、留门守夜，部落防御基建的进度条。[古风]
  例句：竹墙立起来那几天，族人排队围着看，谁也没想到自己能有座"城"。
  提示：用"族人围观惊叹"带出基建爽感，别干报工程进度。

- **半球屋 / 竹屋 / 斜式帐篷** — 从洞穴到竹屋的定居升级：伤口潮湿搭帐篷、砍竹编墙盖屋。[古风]
  例句：竹屋搭好的那天，他前前后后转了三圈，忍不住伸手拍了拍那面竹墙。
  提示：住"升级"是安稳感的可视化，新屋落成＝剧情告一段落的仪式感。

- **号角 / 骨哨传讯** — 号角节奏代表含义、骨哨一响全员集结，原始部落的通信系统。[古风]
  例句：骨哨一响，夜巡的、守陷阱的、编草鞋的，全都扔下手里的活往空地跑。
  提示：写"全族响应"＝部落动员力的显影，比报人数直观。

- **部落积分 / 按劳兑换（锡竹币）** — 干活多、打仗立功发盐发币，刻花纹的锡竹片当货币换仓库物资。部落经济雏形。[古风]
  例句：部落造出了一种锡竹币，谁干活多谁币多，仓库里的东西都能拿币换。
  提示：经济线是种田文的"成就感刻度"，定兑换标准→发布规则→发币都是小爽点。

- **奖励机制 / 论功行赏** — 首领把战利品按功劳分：宰羊犒劳、赏粗盐，赏罚分明才有人肯卖命。[古风]
  例句：这趟狩猎回来的羊，按谁出力多分肉——规矩立住了，族人才肯跟着拼命。
  提示：先立"按劳分配"再写"人人抢活"，是部落管理戏的递进；与积分条互为表里。

- **分配任务 / 流水协作** — 男人砍竹建墙、女人编草鞋鞣皮子、小家伙看陷阱，部落的项目管理。[古风]
  例句：壮劳力去砍竹建墙，女人们编草鞋，半大的孩子看陷阱，一个下午，部落像上了油的机器。
  提示：分工段落＝"部落变强"的蒙太奇，一笔带过多项，别逐项展开。

- **"首领，我！"式抢活** — 族人为立功争相请缨，被派任务的人像得了天大便宜。轻松向群像。[古风]
  例句："首领，我可以！"话没说完，几个年轻人已经挤到前面去了。
  提示：写"抢着干活"＝首领威信立住的证据，比正面吹捧自然。

- **部落学堂 / 文字传承** — 教简体字、建学堂、刻竹简记账，文明播种线。[古风]
  例句：学堂里那些小崽子刚学会写自己的名字，就急着刻在墙上到处显摆。
  提示：文字=文明跃迁点，配"小孩子显摆/记账吵架"的生活化细节，别写成科普。

- **"盐"硬通货** — 没盐的烤肉腥得难以下咽，盐矿石＝见面礼＝外交货币，资源稀缺驱动剧情。[古风]
  例句：对方送来的那一包盐矿石，比送一筐猎物还让他开心——部落正缺这个。
  提示：稀缺资源是"找矿/贸易/抢地盘"三条支线的公共入口。

- **部族语言生涩（单字蹦）** — 原始语发展缓慢，说话只能一个词一个词蹦，靠动作比划。反差萌点。[古风]
  例句："你，族人……"他指着对方，又指了指自己，憋了半天才把话说完。
  提示：语言不通是"误会笑点"的天然来源，也侧面交代世界文明程度。

- **便宜父亲 / 族长也保不住** — 生存法则面前亲情让位：族长的儿子返祖失败同样被逐。写部落法则的冷与主角开局。[古风]
  例句：哪怕他父亲是族长，也没能保住他——部落的规矩，比族长的脸面大。
  提示：先立"冷酷规则"，后面的"破坏规则/建立新部落"才解气。

- **"只吃原兽"部落的异类气质** — 主角不吃兽耳人、不搞人祭的"文明底线"，在原始部族里是异类也是信仰。人设主线。[古风]
  例句：别族嘲笑他连送上门的祭品都不要，他却说，吃人的规矩，从今往后在部落里废除。
  提示：把现代价值观植入原始社会＝种田文的价值观爽点，配"族人从将信将疑到跟随"。

## 网文补充（诸界末日 提炼）

> 末世场景 / 副本世界 / 诸天 / 规则 / 危险区。本书主产出，新建 `realm-world.md` 用。定位：现有词库的 xianxia·秘境（偏仙侠）与都市异能·副本（偏现实）之外，补「游戏化末世 + 多层世界 + 战役判定」的诸天中段。

- **游戏降临现实** — 末世开场设定：本来只存在于"游戏"里的世界凭空压进现实，全人类被卷入，无人能退出。[通用]
  例句：游戏降临现实的那天，整座城的人都以为只是抢到了一次内测资格——直到怪物从楼顶爬下来，再也没人回得了线。
  提示：开篇定基调；配"普通玩家以为能下线→尸体不会刷新"的反转。

- **诸界 / 亿层世界** — 多层世界叠加的世界观核心词：无数世界堆叠，层与层之间靠世界之门/虚空连接。写格局拉升。[通用]
  例句：老人说，这方天地不过是万千层世界中的一层，往上还有数不清的世界叠着，每一层都住着别的生灵。
  提示：写世界观揭底、高维文明、终极反派登场前的格局话术。

- **世界之门** — 世界之间的出入口：撞开/撕裂门扉，就能进入另一层世界。门另一头常连"已毁灭的世界"或"敌界军队"。[通用]
  例句：世界之门在半空裂开一道缝，门里涌出来的不是救兵，是黑压压的魔物。
  提示：写诸天穿梭、入侵开启、救兵到达的高能节点；配"门缝漏出的光/气息"先声夺人。

- **虚空乱流** — 世界夹缝中的狂暴通道：光膜裹着人在乱流里穿行，空间被撕开又合拢。写"跨界路线"。[通用]
  例句：他裹着那层光膜扎进虚空乱流，四周全是空间被撕开又合拢的闷响，多看一眼都心悸。
  提示：写穿越世界的途中戏；"乱流里什么都别动"可立成保命铁律。

- **虚空取物 / 虚空储物** — 随身空间设定：器物藏于虚空，抬手一探即抽出兵刃。写金手指的展开与出招起手。[通用]
  例句：他抬手在虚空中一探，长刀无声地滑了出来，像是早就藏在那里等他。
  提示：写"虚空一握"式出招、储物挂；与"凭空出现"可轮换。

- **平行世界** — 与主线并行的另一世界：可被开辟、可被入侵，也可能是"无数个自己"集结的战场。[通用]
  例句：为了对抗那场末日，他斩开平行世界的屏障，找来了一群"自己"并肩作战。
  提示：写多重身份、跨世界援兵、镜面世界揭底。

- **已毁灭的世界** — 副本背景板：误入一片死寂世界，只见废墟与枯骨，没有任何活物。写"前车之鉴/末日终局"。[通用]
  例句：这里曾是一座繁华的城，如今只剩断墙在风里呜咽——这是一方已经被毁灭的世界。
  提示：写副本入口、警示场景、大反派"毁过世界"的战绩。

- **黄泉世界 / 黄泉之气** — 末日阴间系设定：世界衰败时渗出黄泉阴气，人死入黄泉轮回。写"死亡的另一面"。[古风]
  例句：暗灰色的气息从地底漫上来，老兵脸色一变：黄泉之气，末日的端倪已经出现了。
  提示：写灾变前兆、死灵系敌人、主角与死亡的交易。

- **恶鬼世界（把人转化为恶鬼）** — 敌方副本世界模板：鬼王掠夺活人，把人类活活转化为鬼兵。写"阵营+转化机制"。[通用]
  例句：那个世界早已被恶鬼占满，抓去的活人一个个被拖进鬼窟，再出来时，已是同类。
  提示：写亡灵/鬼物阵营的补兵机制；"被转化的熟人"是情感刀。

- **尘封世界** — 被封存无数纪元的世界或遗迹：门扉一开，远古的规则与力量苏醒。写"上古秘密"的容器。[通用]
  例句：那是尘封了不知多少纪元的世界，门扉开启的刹那，久远的叹息声从门内涌了出来。
  提示：写上古战场、旧日文明、远古神器的所在地；配"唤醒"的仪式感。

- **永恒深渊** — 世界体系最底部的恐怖所在：无法归类的怪物/凶神都从这里爬出。写"最深的危险源头"。[通用]
  例句：那怪物并非此界所生——它来自乱劫之外的永恒深渊，那里盘踞的东西，诸神都不敢看。
  提示：写终极反派/未知恐怖的来源；比"地狱"多一层宇宙尺度的冷。

- **六道轮回** — 转世/复活机制的设定：死亡不是终点，灵魂按业力投胎六道。写生死规则与重生解释。[古风]
  例句：这方世界有六道轮回，人死魂不散，自有归处；可轮回之口，也会吞下不该吞的东西。
  提示：写生死规则、主角重生的世界观解释、阴间线。

- **回到过去（游戏背景中的过去时光）** — 主角重生进游戏故事线的初始时代，知道历史结局却无力改变。写"重生者/历史介入者"。[通用]
  例句：他记得这场战役的结局——全军覆没。可他偏偏被丢进了这段早已死掉的时光里。
  提示：重生流的"先知优势+无力感"双重张力；配"想改变却处处受制"。

- **战役判定：XX失败** — 全服/全界级大战的结果播报，一句话判决一个世界的存亡。[通用]
  例句：天空裂开一道口子，冰冷的宣告响彻大地："人族王城被攻破，战役判定：人族失败。"
  提示：写大决战、世界存亡的转折点；判定一落，世界开始"死"。

- **死人坑（尸坑）** — 末世战争集中弃尸地：尸体成堆、血腥气引妖兽、暴雨冲刷。写"战争余烬"的定点危险区。[通用]
  例句：军营外的死人坑堆了几层尸体，一场暴雨过后，血腥味顺着风能飘出十里。
  提示：写前线、战场、庇护所外的警示地带；尸坑=死亡的量词。

- **隐匿法阵 / 营地庇护所** — 末世基地的核心防御：靠灵石维持的隐匿屏障，法阵一破妖魔长驱直入。写"庇护所的命门"。[古风]
  例句：营地的隐匿法阵越来越虚弱，再没有灵石补充，法阵一散，妖魔就该进营了。
  提示：写基地防御、资源告急、守夜戏；法阵=安全感的具象。

- **异界人族一败再败** — 末世大局：异界人族节节败退，玩家是最后填进去的炮灰。写"大势将倾"的悲壮背景。[通用]
  例句：亿万人涌进异界帮忙守城，可每一场决定性的战役，人族还是一败再败。
  提示：写末世大势、主角逆天改命的动机；败局先立住，翻盘才值钱。

- **时间流速差（异界一天，现实一小时）** — 双世界时间不对等：异界修炼一整日，现实才过一小时。写"两界往返"的节奏设定。[通用]
  例句：异界一天，现实才过去一个小时——炼气期的玩家掐着点，进进出出地练级。
  提示：写往返世界的时间安排；"该回现实了"是每一轮的截止线。

- **序列 / 序列等级** — 高维秩序体系：人、神、万物皆被编入序列，序列越高越接近世界规则本体。[通用]
  例句：他们的序列等级几乎冠绝整个世界，可连他们也不知道，末日真正的来头。
  提示：写大能等级、幕后秩序；"最高序列"是接近造物主的位阶。

- **世界之术 / 法则之术** — 触及世界底层规则的力量：不是打架，而是改写世界运行的"程序"。写终极战力体系。[通用]
  例句：真正决定世界存亡的，从来不是谁的剑快，而是谁握着世界之术。
  提示：写终极反派/主角压轴底牌；与普通武力拉开"规则级"差距。

- **灵魂本源** — 力量体系的底层解释：修行、神技、神通，究极都来自灵魂。写"力量的来源"。[通用]
  例句：师尊说，众生最根本的力量来自灵魂的本源——肉身会朽，灵魂的火种不灭。
  提示：写境界设定、突破大关、觉醒神技的根因；灵魂=可再生资源。

- **神器命名模板（地名+职司+器物）** — 神器的命名格式：六界神山剑、忘川离魂钩、镇狱鬼王杖——地名+职能+器物，一件神器自带一个世界级背景。[古风]
  例句：六界神山剑、忘川离魂钩、镇狱鬼王杖——黄泉世界的三件至宝，每件都镇着一截轮回。
  提示：写神器设定模板；"地名+职司+器物"天然有故事感。

- **神器器灵** — 神兵化形为人的设定：剑有灵、塔有灵，器灵通人性、记得千万年往事。写"神器的人格化"。[古风]
  例句：那柄剑的器灵化形而出，是位身着青衫的仕女——她守着这方世界，已经等了三万年。
  提示：写陪伴型金手指/情报源；器灵=随身百科+性格担当。

- **结界外妖魔横行** — 末世危险区定调：结界之内是文明，结界之外妖魔横行。写"生存半径"。[通用]
  例句：出了隐匿法阵，外面就是妖魔横行的野外，普通人撑不过一晚。
  提示：写"出城=玩命"的野外戏；结界=文明最后的边界。

- **末日的端倪** — 灾变前兆的悬疑写法：天象、气息、异响先行，真正的毁灭还藏在后面。写"大难将至"的铺垫。[通用]
  例句：暗灰色的烟雾贴着天幕漫过来——老兵说，这是末日的端倪，后头还有更大的东西。
  提示：写"前兆→拉开毁灭"的两段式；前兆越平静越渗人。

- **游戏的真相（这不是游戏）** — 末世世界观的反转钩子：当第一件装备被带出"游戏"，普通人才发现这不是娱乐。[通用]
  例句：直到第一件兵器被人从游戏里带进现实，平凡的人们才发现——这并不是游戏。
  提示：开篇/中期的世界观反转；"不是游戏"是全书第一声惊雷。

- **平行世界的碎片** — 平行世界无法被完整开辟，只能形成"片断"。写"诸天不够格"的局限设定。[通用]
  例句：倾尽人族之力，也开不出一个完整的平行世界，只能勉强拼出些片断供人藏身。
  提示：写世界等级差距、避难所/镜像空间的无奈；"只能如此"=末世的退让。

- **万兽深窟（兽道世界）** — 兽族为主的副本世界：深窟内万兽繁衍，兽王传人承其道统。写"御兽系世界"。[古风]
  例句：那深窟里住着亿万兽类，最深处是兽王的巢——踏过万兽尸骨，才配继承它的道统。
  提示：写兽族阵营、御兽流世界；"深窟"自带层层深入的压迫感。

- **魔君皇廷（敌方大本营模板）** — 反派大本营命名："魔君/鬼王/妖圣"+"皇廷/王庭/行宫"。写敌方势力核心地带。[古风]
  例句：魔君皇廷压在世界的尽头，皇廷之后是一片虚空乱流，直通那个被毁灭的世界。
  提示：写最终副本/BOSS老巢；"皇廷后门"是潜入绕后的路线设计。

- **大铁围山（奇观地标）** — 巨型山体类地标：连天接地的黑山，是世界的边界、封印、神器的原点。写"不可翻越的规则"。[古风]
  例句：那座大铁围山横在天边，黑得像一口倒扣的锅，没人知道山那边是什么。
  提示：写世界边界、封印之地、终点副本；山体=规则本身。

- **九亿层世界（格局话术）** — 世界观格局句：把"世界"当楼层数，层数越大宇宙越深。配"数不清/全都是真实的"强调。[通用]
  例句：九亿层世界，数不清的亿万个世界，全都是真实的——你以为的主场，只是其中一层。
  提示：写格局拉升、多元宇宙观；数量级=深度。

- **死人坑中苏醒（开篇镜头）** — 末世/战场的经典开场：主角从尸体堆里醒来，满身血污，不知道自己在哪年。写"灾难开场"。[通用]
  例句：他从死人坑里醒过来，满身血污，天色如墨——伸手一摸，怀里还握着一把陌生的弓。
  提示：开篇定场用；"哪里醒来+手里握着什么"直接抛出悬念。

- **世界法则异于现实** — 进入异界后常识失灵：灵力、神通、法则与现实全然不同。写"异界初入"的陌生感。[通用]
  例句：到了这个世界，他才明白什么叫法则不同——在这里，一句真言能劈开一座山。
  提示：写初入异界的"世界观教学"；法则差异=异界感的核心。

- **玩家涌入异界（全民战争）** — 末世"全民化"设定：现实人类成批涌进异界当玩家/炮灰。写"两界联动"。[通用]
  例句：那一年，数以亿计的人类涌进游戏，帮异界的人族抵御妖魔——可还是挡不住。
  提示：写末世大背景、人类共同命运；"人人都在参战"=格局。

- **游戏世界即真实世界** — 设定反转：异界不是数据，里面的人有血有肉，死了就是真死。写"世界真实性"的揭示。[通用]
  例句：这个世界里的人都有血有肉，把他们当成数据，是最大的傲慢。
  提示：写"意识到是真的"的认知冲击；配主角对NPC态度的转变。

- **最终魔主 / 最终战役** — 末世终局BOSS与决战：一切毁灭的源头，战胜它世界才有一线生机。写"终极目标"。[通用]
  例句：末日来临的那一刻，他拼尽全力斩杀了最终魔主，可结果，自己也没能退出游戏。
  提示：写终局之战/全书最高潮；"杀了BOSS也没能出去"是反转钩。

## 网文补充（进化骷髅 提炼）

：进化体系 / 亡灵 / 异界构建（30 条，本书主产出）

- **种族进化 / 进化途径** — 三维属性（力量/体质/精神）满点后触发种族跃迁的成长核心：从"低阶骷髅"逐级进化成"坚硬骷髅→元素骷髅"，进化流骷髅/异兽文的等级天花板。[通用]
  例句：当力量、体质、精神三项全部达到十点，便会获得一次进化的机会。
  提示：进化线先给固定主线再开分支（低阶大地骷髅/低阶海洋骷髅），读者才有"养成"的追读感。

- **等级上限（lv10/lv25…）** — 每个种族/职业的成长天花板，卡住"升到顶→凑条件→破上限"的节奏，是章节推进的齿轮。[通用]
  例句：他在骷髅怪里也只是最低级的那种，等级上限只有十级。
  提示：写"卡级→攒进化条件→进化"循环；面板里可用英文缩写，正文叙述换成"十级"更贴文风。

- **灵魂之火** — 亡灵生命的核心，藏在颅骨/胸腔里的一团幽蓝火焰，火灭即亡；同时是亡灵唯一的"脸"——摇曳是慌、升腾是怒。[古风]
  例句：他的灵魂之火被压缩得凝实无比，任凭狂风吹拂也不灭。
  提示：写亡灵系把"心跳/脸色"全换成"火焰"——火苗晃动就是紧张，骤亮就是起了杀心。

- **骨质劣化** — 亡灵骨骼失去血肉滋养、随时间崩解的状态，给骷髅主角挂一个"倒计时危机"。[古风]
  例句：失去了肉体的滋养，他的骨骼开始劣化，骨头还剩一年的寿命。
  提示：劣化→换骨续命→再劣化，生存压力就是骷髅流的主引擎。

- **死亡之力** — 浸染亡者的侵蚀性力量：既能给自己挂负面状态（体质/力量下降），也能注入敌人体内做持续破坏。[古风]
  例句：一剑没入胸口，死亡之力顺着伤口注入，对方的气息肉眼可见地衰败下去。
  提示：亡灵系"毒"的替代——不写腐烂，写生气被吸走的衰败感。

- **换骨续命 / 借骨头** — 亡灵拆更强的同类骨骼替换自身，边补寿命边白嫖技能，"升级流骷髅"的核心玩法。[古风]
  例句：看来得勤快点，从同事身上多借几根骨头了。
  提示：配"物色目标→偷摸下手→装傻混过"的三拍，鸡贼感是这条的笑点。

- **低阶骷髅→坚硬骷髅→元素骷髅** — 骷髅系经典进化阶梯：一碰就碎的杂兵→骨质硬化→掌握元素，三档一眼看懂强弱。[古风]
  例句：从一碰就碎的低阶骷髅，变成骨骼坚硬的骷髅，再融合骨龙犄角，进化成元素骷髅。
  提示：进化要写"火焰升腾席卷骨架"的过程镜头，别只报一行字。

- **特殊种魔物** — 同族里的异类形态，比普通魔物强一大截、自带稀有掉落，地图上的"精英怪"。[通用]
  例句：特殊种是寻常魔物的特殊形态，比同族强大得多，一头就能顶一支小队。
  提示：给特殊种交代成因（变异/上位种/吞噬），否则只是换皮的强化兵。

- **魔石 / 魔物结晶** — 魔物体内凝结的能量结晶，击杀战利品的通用货币与材料，异世界战斗经济的底层。[古风]
  例句：他从火蜥蜴人王的尸体里挖出一枚魔石，入手温热，还在微微发烫。
  提示：魔石按属性分色（火红/深蓝），写"结晶体量"交代魔物强弱。

- **地下城（城标塔 / 阶层）** — 层数一路往下延伸的迷宫，地表用城标塔标记入口，深层能见到"天空"；冒险者的资源产地。[古风]
  例句：每一座城标塔之下都有一座地下城，层数越深，魔物越强。
  提示：写"进城"先交代层数体系，主角每一步升级都对应一层"攻略难度"。

- **地下城核心** — 整座地下城的控制中枢，只有地下城魔王能操纵，可传送、投影、改造地形。[古风]
  例句：他催动地下城核心，瞬间被传送到了迷宫的第一层。
  提示：给核心挂"权限"感——能造什么地形、放什么怪，就是经营流的进度条。

- **地下城魔王 / 魔王面板** — 地下城的统治者，手握"随意支配改造地下城"的权限，经营系主角的身份位。[古风]
  例句：魔王可以随意支配、改造自己的地下城，也能向所有魔物下令。
  提示：魔王视角的爽点在于"领地越改越强"，别写成只会蹲层的守门boss。

- **阶层boss（守层BOSS）** — 镇守地下城某一层尽头的精英怪物，击杀掉落丰厚，是"攻略完这一层"的终点标记。[通用]
  例句：杀穿一整层魔物，最深处蹲着的才是这层的守层boss。
  提示：守层boss要给"初见压迫→找到弱点→瞬杀"的反差节奏。

- **冒险者协会（接任务 / 等级晋升）** — 异世界冒险者的调度中枢：发布任务、按难度分级、按履历晋升，主角混社会的窗口。[古风]
  例句：任务以发布、领取、奖励的制度分级，合理地调动着冒险者。
  提示：写"接任务"顺带交代主角身份位（新人/中阶），履历即人设。

- **魔法学院 / 魔法协会** — 法术传承的官方机构：学院管培养、协会管规则与监制，是"正规魔法师"的身份背书。[古风]
  例句：四阶以上的魔法，只有找到高阶魔法老师，才学得会。
  提示：写"科班 vs 野路子"的鄙视链，是魔法世界常用的阶级落差素材。

- **一阶魔法→九阶魔法（魔法等阶）** — 魔法按阶位划分的威力标尺：一至三阶低阶、四至六阶中阶、七至九阶高阶，阶位即魔法师名片。[古风]
  例句：魔力够到四阶的标准，也还算不上正式的四阶魔法师。
  提示：报等阶要带"门槛"，阶位差（准X阶）本身就能当冲突。

- **魔法模型** — 中高阶魔法的原理骨架，施法前要在脑中"建模"，掌握模型才能放出对应法术，魔法研究流的核心设定。[古风]
  例句：四阶魔法需要掌握对应的魔法模型，照着模型勾勒，法术才成形。
  提示：写"现学模型→实战验证"是主角创新流的名片，比单纯报技能名有深度。

- **混合魔法** — 多种元素/系别揉在一起的改良法术，主角创新流的名片，比单系魔法贵一档。[古风]
  例句：他把土石与火焰叠成复合法术，一炮轰出去，既有重量又有灼烧。
  提示：混合魔法要写"组合逻辑"（为什么这么搭），别只喊名字。

- **元素法师 / 元素系职业** — 专精元素魔法的职业分支，元素法师是魔法师转职的方向，掌管破坏与毁灭。[古风]
  例句：解锁十级可选职业后，他直接转成了元素法师。
  提示：转职要有"选择"镜头（几个职业摆在面板上），选择即人设。

- **元素精灵 / 元素之神** — 元素的具象存在：元素精灵是元素之神陨落后的残响，掌管一系元素的权柄。[古风]
  例句：火之精灵于空中起舞，整片战场的火焰都在响应它。
  提示：写"精灵显威"用"整片同类元素跟着动"的大场面，比报数值有神性。

- **元素之理** — 对元素本质的至高感悟，融合进自身骨骼/躯体后产生质变，神级设定的"理"层力量。[古风]
  例句：感悟元素之理后，他骸骨深处每一寸都透着元素的光晕。
  提示："理"层力量要写得抽象又具体——光晕/共鸣/万物回应，别解释过头。

- **封印之力（封印术）** — 把力量/存在锁死的禁制体系：可封触者之力、可把活物改造成封印载体（封印之树）。[古风]
  例句：那道封印一点点蚕食着触碰者的力量，越挣扎越虚弱。
  提示：封印类剧情配"解封倒计时"当钩子，别一封印就无事发生。

- **原初级造物（原初红宝石 / 原初死亡）** — 世界上第一枚/第一例的传说级存在，自带"万法之源"的格调与威能。[古风]
  例句：原初红宝石，世界上第一枚红宝石，传说中藏着世界最初的色彩。
  提示："原初"二字一出就是格调上限，一本书用一两个当压轴设定，多了不值钱。

- **哥雷姆** — 以泥土/矿石为材料造出的人造魔物，主人能共享视角、下派任务，是亡灵系主角的"造物班底"。[古风]
  例句：他揉了一团泥，灌注魔力，一只粗手粗脚的哥雷姆从地上爬了起来。
  提示：写"造物"要留粗糙感（关节/脖子是弱点），越笨拙越有养成空间。

- **白骨之王（白骨大军）** — 亡灵势力的顶点称号：麾下骷髅大军、宫殿由白骨堆砌，"王者归来"的经典亡灵意象。[古风]
  例句：白骨之王离去，他的追随者在此徘徊，等候王归来的那天。
  提示：白骨王座/白骨宫殿/亡灵大军三件套，写"亡灵势力现世"的排场。

- **传送魔法** — 空间系法术，公认难学、会的人少，主角靠它实现"地下城任意层瞬移"的机动优势。[古风]
  例句：传送魔法没几个魔法师会，大多数人一辈子也摸不到空间的门槛。
  提示：给传送加消耗/距离限制，别写成无冷却位移挂。

- **魔法道具（品级）** — 附着法术效果的装备，按品质分高品/传说级，材料多出自地下城，是异世界战力经济的一环。[古风]
  例句：一些高品魔法道具和装备，也都是从地下城带出来的。
  提示：道具品级用"传说级"撑场面，但正文要用具体效果证明，别只挂名号。

- **记忆结晶 / 魔力结晶** — 记忆结晶封存知识与感悟、注入即得；魔力结晶凝聚法师一身魔力，是传承与战利品的载体。[古风]
  例句：他把那块记忆结晶贴身收好，里面封着一位八阶法师毕生的感悟。
  提示：记忆结晶是"灌顶式学知识"的现成容器，写主角吞结晶=开外挂但要有消化过程。

- **生命之火（亡灵的倒影）** — 与"灵魂之火"相对的原初火焰意象，灰烬可做传说级道具材料，亡灵系的世界观钩子。[古风]
  例句：火焰便是生命之火，而灰烬，是后来传说级道具的原料。
  提示：用"火→灰→道具"的因果链做世界观钩子，一句话铺出故事线。

- **种族克制设定（惧光/惧净化）** — 亡灵与魔物的种族弱点（吸血鬼惧光、骷髅惧净化圣光），写"克制相"给主角留破局空间。[古风]
  例句：吸血鬼拥有惊人的自愈，可偏偏一见日光就虚弱下来。
  提示：给种族弱点，主角才能"以短胜长"——弱点越明确，越级打法越好写。


## 无上限补强（兽娘部落 提炼）

- **雪橇 / 爬犁** — 雪原交通工具，滑行拉物、载人赶路，极地部落的效率外挂。[古风]
  例句：几只雪狼套上绳，拉着装满柴火的爬犁，雪面上划出两道深深的辙印。
  提示：写"雪原赶路"配"压实的雪面 + 阻力小"；有狼群=现成动力，比步行省一半天数。

- **冰钓 / 凿冰 / 冰窟窿** — 冰面凿洞垂钓的生存技能，冬季最稳的口粮来源。[古风]
  例句：用骨尖在冰面上凿出个拳头大的窟窿，鱼影刚凑过来就被一叉子扎住。
  提示：写"凿洞→看鱼→下叉"三步，把一餐饭写成一场小胜仗。

- **水井 / 打井** — 定居基建，挖出甜水井＝部落真正扎根的标志。[古风]
  例句：那口井打下去第三天才见水，浑浊的泥浆一涌出来，围着的族人都欢呼了。
  提示：写"从河边挑水→自家打井"的基建升级，是定居点成立感的来源。

- **粮仓 / 地窖** — 部落储粮的两种形态：地上粮仓、地下地窖，存粮＝过冬底气。[古风]
  例句：地窖里码着一层层的肉干和盐，够整个部落撑过最冷的那三个月。
  提示：写"囤积"的踏实感，盘点时按"能撑多久"换算。

- **磨面 / 石磨** — 把谷物磨成粉的加工环节，粮食从"能吃"到"好吃"的跨越。[古风]
  例句：石磨吱呀吱呀转，麦粒变成细面落下来，整个部落都闻得到面粉的香气。
  提示：写"文明加工"的成就感，配"头一回吃上面食"的惊叹。

- **养蜂 / 蜂蜜** — 甜味来源，原始部落最稀罕的奢侈食材。[古风]
  例句：那一罐蜂蜜被当成宝贝，平时锁在木箱里，只有过节才舀一小勺。
  提示：写"稀缺甜味"用"一小勺/锁起来"的珍惜感。

- **岗哨 / 放哨** — 部落警戒的第一道防线，守夜看大门的日常。[古风]
  例句：山口立了个简单的岗哨，白天看有没有外人来，夜里看火堆还亮不亮。
  提示：写"建哨位→排班→报信"是部落安全感的具象。

- **兽夹 / 陷阱夹** — 捕猎辅助器械，设伏比追猎省力。[古风]
  例句：沿着兽道埋了三副兽夹，第二天一早，夹住了一只瘸腿的雪兔。
  提示：写"布夹→验收"的间隔节奏，给读者留"会不会有猎物"的悬念。

- **水渠 / 灌溉** — 种田水利，引水入田的基建升级。[古风]
  例句：从溪边挖了条浅浅的水渠，把水引到田里，省去了肩挑手提。
  提示：写"挖渠→放水→看它流进田"的线性画面，基建即进度条。

- **开垦 / 翻地 / 插秧** — 种田工序的起手三连，从荒地到苗圃的转化。[古风]
  例句：翻地、整垄、插秧，一套下来腰都直不起来，可田里终于有了一片青苗。
  提示：写工序的累，累里带盼头；别只报"种地"，要有泥土和汗。

- **打谷 / 脱粒** — 收割后的加工环节，丰收的最后一步。[古风]
  例句：把晒干的穗子往木板上摔打，谷粒噼里啪啦地落了一地。
  提示：用"摔打→落粒→装袋"写丰收的踏实感。

- **酿造 / 葡萄酒 / 蒸馏** — 粮食果物的再加工，部落富起来才玩得起的进阶手艺。[古风]
  例句：第一坛果酒封坛那天，他特意用兽皮把坛口糊了又糊，就盼着开坛那口香。
  提示：写"酿酒→封坛→等待开坛"，时间差就是期待感。

- **蜜饯 / 糖渍** — 用糖或蜜腌渍果子，把容易坏的食物变成能存的甜点。[古风]
  例句：山楂果熬成糖浆泡上，晾干就成了红彤彤的蜜饯，小孩馋得直咽口水。
  提示：写"加工延长保质期"，配"孩子围着看"的馋相。

- **腌制 / 熏制 / 腊肉** — 肉类保存的三种手法，猎物多的季节攒过冬口粮。[古风]
  例句：冬天的猎物杀完不能放，抹盐、上架、烟熏，屋檐下挂了一排腊肉。
  提示：写"保存"即"安全感"；配"看着肉干慢慢变色"的时间感。

- **孵化 / 产卵 / 断奶** — 驯养动物的繁殖流程，从"养一只"到"养一群"的转折。[古风]
  例句：第一批蛋孵出小崽那天，整个部落都跑来围观，比过节还热闹。
  提示：写"繁殖成功"＝养殖线里程碑，配"数着几只成活"的欣喜。

- **放牧 / 羊圈 / 鸡舍** — 圈养与放牧的棚舍，畜牧业的固定设施。[古风]
  例句：羊圈围起来那天，再也不怕夜里被兽叼走，族人们都睡得踏实了。
  提示：写"搭棚→圈养→省心"是定居文明的标志物。

- **铜币（货币经济）** — 部落从以物易物转向钱币流通，经济跃迁的刻度。[古风]
  例句：自打铜币流通起来，交易不用再背着一筐兽皮去换盐了。
  提示：写"货币取代实物"＝集市成熟的标志；配"物价/找零"的日常感。

- **行脚商人 / 流动摊贩** — 走村串部落的货郎，情报与物资的移动枢纽。[古风]
  例句：行脚商人的担子一落地，围上来的人比过节还多，稀奇货一件件往外掏。
  提示：写"货郎到来"＝物资线+情报线一起开闸，是转场利器。

- **传声海螺（远程通讯道具）** — 异世界版对讲机，跨地联络的情报工具，部落奇物/商城道具皆可。[古风]
  例句：隔着两座山头，靠着那只传声海螺，两边的声音清清楚楚传了过去。
  提示：写"跨地传话"的便利与新奇感；配"放在耳边/对嘴喊"的操作细节。

- **交易聚落（升级版集市）** — 比小集市更成规模的交易市场，各族/各部落的物资集散地。[古风]
  例句：那处交易聚落一到集日就挤满了人，各部落的兽皮、盐、奇物都往这儿运。
  提示：比 realm-world"交易部落（以物易物）"高一级——那个写部落间以物换物，这个写成型市场的繁荣（摊位/人流/吆喝）。

- **星空鬼打墙（宇宙物理奇观）** — 星际中的神秘屏障，飞船反复绕回原点，科技再强也打不破。写"宇宙级谜题"。[通用]
  例句：那艘飞船在星空中绕了上百圈，始终撞不进那片区域——像撞上了星空鬼打墙。
  提示：写"星际禁区/宇宙级封印"；与"量子瓶颈"同族，皆可当主线悬念。

- **太空城（移动太空城）** — 漂浮在宇宙中的巨型城市：生态单元、独立生命维持系统。写"人类在太空的家"。[通用]
  例句：这座移动太空城装载着两万多条生命，是人类在地球之外最后的后路。
  提示：写"星际时代的居住单元"；配"生态单元/水资源"的生存约束。

- **生态聚能电池（科幻黑科技）** — 体积小、续航长的未来能源：一次充电跑一千五百公里。写"技术垄断带来的商业传奇"。[都市]
  例句：他们研发出一种生态聚能电池，体积小、安全性高，一次续航一千五百公里。
  提示：写"黑科技变现/专利垄断"；技术越离谱，商战和打脸越顺。

- **超导科技（超导飞船/超导炮/超导卫星）** — 以超导技术驱动的星际载具与武器体系。写"星际时代的技术底色"。[通用]
  例句：超导飞船、超导卫星、超导炮铺开了人类迈向深空的全部家底。
  提示：写"高科技文明"的装备清单；"超导"一词自带硬科幻味。

- **禁忌科技（文明前十）** — 被文明封禁的危险技术：公认最强也最危险。写"主角的技术底牌"。[通用]
  例句：这张底牌，是火星文明公认排名前十的禁忌科技。
  提示：写"压箱底技术/大招"；"禁忌"二字自带危险与兴奋。

- **时光长河（时光深渊）** — 宇宙级的时间概念：文明更迭如长河奔涌，深渊中藏着旧日。写"时间尺度上的格局"。[通用]
  例句：时光长河起起伏伏，时代文明不断更迭，一切都在变，唯有它亘古永存。
  提示：写"终极反派/古神/时间系能力"；长河=时间的拟象。

- **星空坟场（星际遗迹）** — 漂满旧日飞船残骸的星际墓地：曾辉煌的文明只剩锈蚀。写"前车之鉴/战争余烬"。[通用]
  例句：这片星空坟场里堆着数以万计的飞船残骸，记录着一个文明走向毁灭的全过程。
  提示：写"大战后的星际战场"；残骸=伤亡的量词。


## 无上限补强（诸界末日 提炼）

- **时空乱流** — 时间与空间双重紊乱的通道：世界夹缝里时间流速被搅乱，路过的异象能"吃掉"一整段时间。写"跨界途中/时间线错乱"。[通用]
  例句：时空乱流里景象光怪陆离，有些东西能彻底打乱时间流——老人叮嘱他，过乱流时什么也别看，什么也别做。
  提示：与已有"虚空乱流"（空间撕裂）区分——本条侧重**时间紊乱**，适合写"误入乱流=时间被偷走"。

- **世界碎片 / 碎片世界** — 崩坏世界留下的残片：完整世界被打碎，残片仍自成一界，飘在虚空里供人探索/避难。写"世界的尸体"。[通用]
  例句：那方世界早已碎了，只剩下零星几块碎片悬在虚空，每一块里都还残留着当年的活物。
  提示：写"已毁灭的世界"的下位形态；碎片大小=末日前文明的余温。

- **相位世界** — 与现实重叠却不同相位的异界：人看不见、摸不着，却与现实共享同一空间坐标。写"看不见的邻居"。[通用]
  例句：那是个与现世重叠的相位世界——人就在你身边走过，你却一辈子撞不见它。
  提示：写"擦肩而过的异界"；配"只差一个相位"的错过感。

- **悬空世界 / 浮空城** — 漂浮在虚空或天空中的世界与城邦：不接大地，靠法阵/机械悬浮。写"高高在上的文明"。[通用]
  例句：那座浮空城悬在云海之上，只有一条法力光桥与地面相连——上不去的人，只能仰着头看。
  提示：写"够不着的世界"；浮空城=地位与隔离的双重意象。

- **混沌之墟** — 混沌之力湮灭后的废墟地带：秩序被搅乱过的地方，只剩扭曲的残骸与乱窜的能量。写"世界伤口"。[通用]
  例句：大战过后那片地界化作混沌之墟，残破的天地像被揉皱的纸，再没人敢往里踏。
  提示：写"强者交手后的世界残留"；"揉皱的纸"式扭曲=灾后奇观。

- **死亡之河 / 生死河** — 生死交界处的河流：渡河者交出活人身份，河的尽头是亡者之国。写"死亡边境"。[古风]
  例句：那条河横在生死之间，尸骸在河面漂了不知多少年——活人过河，得先把命押在船上。
  提示：写"通往亡者世界的关卡"；河=生与死的分界线。

- **末日坟场** — 世界末日后的乱葬场：无数纪元覆灭者的埋骨之地，骸骨成山、死气盘旋。写"死亡的量词"。[通用]
  例句：末日坟场里埋着不知多少个纪元的亡魂，一脚踩下去，全是化不掉的骨头渣。
  提示：写"毁灭的终点站"；坟场越大，越衬眼前活人的渺小。

- **大墓（世界之墓 / 终极之墓）** — 通往死者世界的巨型陵墓副本：层层深入，越往下越接近轮回尽头。写"往生的迷宫"。[通用]
  例句：那座大墓不知是谁为谁修的，只知越往深处走，越能听见亡者低语——终极之墓的门口，立着看守轮回的棺椁。
  提示：写"死者世界的入口副本"；大墓=一层层下坠的压迫感。

- **祭命之舞 / 死斗之舞** — 以献祭自身性命为代价的仪式之舞：舞完，命已押给神。写"以命换力的仪式"。[古风]
  例句：她旋身而起，跳起那支祭命之舞——每一步都踏在自己的寿数上，舞落，人瘦了一圈。
  提示：写"燃烧生命的禁术/仪式"；舞的优美与代价的惨烈并置。

- **万灵蒙昧（蒙昧之术）** — 遮蔽整个文明心智的力量：万灵神识被封印，一代代在混沌中繁衍而不自知。写"世界级洗脑"。[通用]
  例句：不知从哪一代起，万灵蒙昧——众生不知道自己困在牢里，只当这一方天地就是全部。
  提示：写"世界观揭底的终极伏笔"；"不知道自己被蒙"是全书级反转。
