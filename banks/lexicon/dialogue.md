# 对话言语词库

> 对话描写。写法要点：**说话方式 > 说了什么**——配合动作、语气、潜台词（scene-craft/dialogue）。词的替换让角色说话有个性（口头禅/身份用语），但别滥用方言。
> 标签：`[通用]` / `[古风]` / `[都市]`。`⚠` = 反 AI 冲突词。

## 说话方式动词

- **低声道 / 压低声音** — 秘密/克制 [通用]
- **沉声道 / 嗓音低沉** — 严肃/权威 [通用]
- **冷笑一声** — 嘲讽 [通用]
- **慢悠悠地** — 从容/施压 [通用]
- **顿了顿** — 停顿，留白 [通用]
- **抢白 / 打断** — 急切/强势 [通用]
- **咬牙一字一句** — 压抑愤怒 [通用]
- **语气平淡，听不出情绪** — 深不可测 [通用]
- **尾音上扬** — 疑问/撩人 [通用]
- **带笑的声音** — 嘴上客气，未必真笑 [通用]

## 语气词/口头禅（角色个性化）

- 古风自称/称谓：**在下 / 贫道 / 本座 / 本尊 / 小爷**——身份即称呼 [古风]
- 古风敬语：**阁下 / 前辈 / 道友 / 施主** [古风]
- 都市口语：**得嘞 / 讲究 / 行吧 / 拉倒 / 上道**——按角色年龄/阶层选 [都市]
- 大佬句式：**"你知道上一个这么跟我说话的人，现在在哪吗？"** [通用]
- 杀伐句式：**"留你全尸。"** / **"你只管试。"** [古风]

## 潜台词提示（网文高阶）

- 表面客气+内里警告："**秦某记下了。**"——记下的未必是恩 [古风]
- 表面推辞+实则应允："**再考虑考虑。**" [通用]
- 试探："**你似乎……知道点什么？**" [通用]
- 施压："**我给你三个数。**" [通用]
- 拒绝但不撕破脸："**道不同。**" [古风]

## 网文补充（玄鉴仙族 提炼）

> 全书扫描 + 精读筛选产物，写作导向释义 + 通用化例句。

- **恭声应道** — 弟子/下人答话的标准腔，规矩又给足面子。[古风]
  例句：他恭声应道："是，弟子遵命。"
  提示：写"应声"时配"低头/弯腰"，别整章都恭声。

- **正色道** — 收起玩笑、认真表态的说话方式。[通用]
  例句：他正色道："此事关系重大，不可儿戏。"
  提示：写"摊牌/警告/表态"的转折，与玩笑腔形成对比。

- **郑重其事地开口** — 郑重的正式发言，议事/立约场合用。[古风]
  例句：他郑重其事地开口："还请家主成全。"
  提示：写求人、立誓、宣布大事，比"认真地说"有分量。

- **一字一句** — 咬着字慢慢说，强调/施压的说话节奏。[通用]
  例句：他一字一句："今日之仇，我必百倍奉还。"
  提示：写"放下狠话/做承诺"，配"声音放轻"更有威胁。

- **答得滴水不漏** — 圆滑应对，不给对方可抓的破绽。[通用]
  例句：那管家答得滴水不漏，问不出半点破绽。
  提示：写老油条、世故之人的应对，反衬主角套话失败。

- **"在下……，见过道友"** — 修士见面自报家门的标准句式，江湖规矩的开场。[古风]
  例句："在下青霄宗陈三，见过道友。"
  提示：写"初次见面/宗门社交"的自我介绍，一句定礼数。

- **"X宗修士……，奉师命前来拜见"** — 登门通报句式，体面又带压迫感。[古风]
  例句："云水宗修士玄真，奉师命前来拜见！"
  提示：写"大佬来访/通报身份"用，名字后挂宗门＝亮背景。

- **慢条斯理** — 从容不迫的说话方式，上位者施压专用。[通用]
  例句：他慢条斯理地抿了口茶："急什么。"
  提示：写"运筹帷幄/不把对方当回事"的节奏。

- **话音一转** — 说话突然转向，带出新话题或情绪转折。[通用]
  例句：他先夸了两句，话音一转："不过，你可知错？"
  提示：写"先扬后抑/话中有话"的转锋，配"语气一沉"。

## 网文补充（不是哥们魅魔 提炼）

> 全书扫描 + 精读筛选产物，写作导向释义 + 通用化例句。

> 都市口语对白/损友互怼/直播间弹幕梗。

- **"你说话怎么这么粗鄙！""你说话还怪哲学嘞！"** — 文人腔 vs 地痞腔对喷，腔调反差即笑点。[都市]
  例句："你怎么说话这么粗鄙！""你说话还怪哲学的嘞。"
  提示：互喷要让两边都成立，别写成单方面挨骂。

- **死装** — 吐槽对方装模作样，损友互怼高频词。[都市]
  例句："整天就在这死装，现在知道不好意思了吧。"

- **菜菜，捞捞** — 大学生求捞/吐槽老师给分的网络梗，校园戏调味料。[都市]
  例句：那么简单的卷子，小学生都写得出来，还有脸说老师菜菜捞捞？

- **好好好，这么来是吧？** — 被套路/被针对后的摆烂式吐槽，翻篇换节奏的口子。[都市]
  例句："好好好，这么来是吧？"他气笑了，撸起袖子。

- **又双叒叕** — 叠字强化"反复发生"，搞笑升级，常用于循环笑点。[都市]
  例句：他刚把人扶起来，小朋友又双叒叕坐回了地上。

- **带恶人** — 弹幕风的搞笑标签，给"反派/不好惹的人"贴梗化封号。[都市]
  例句：人前带善人，人后带恶人，他早看穿了。

- **串台** — 多身份/多任务记混的笑点，词源直播间串场。[都市]
  例句：两个客户的喜好记岔了，他差点当场串台。

- **"你尽管问，我XX多年，什么不知道？"** — 拍胸脯装逼接下茬，给主角递话茬的捧哏句式。[都市]
  例句："你尽管问，我纵横小说网站多年，什么词不知道？"
  提示：接"被打脸/被考倒"的后续更妙。

- **"你是老板，完全OK！"** — 敷衍式应承，表面捧实则摆烂，打工心态金句。[都市]
  例句："行行行，你是老板，完全OK！"

- **弹幕刷屏句式（弹幕：……）** — 直播互动直接上"弹幕：内容"呈现，群众嘴替。[都市]
  例句：弹幕疯狂刷屏："这就是你说的简单？"

- **"这条狗快死了就救一下，那条狗胜利了就踢一脚"** — 毒舌比喻式损人，暗讽卸磨杀驴/现实规则。[都市]
  例句："这条狗快死了，就救一下；那条狗赢了，就踢一脚。"
  提示：狠话用比喻说出来，比直骂有味道。

- **"出来混，讲的是XX"** — 江湖/职场黑话定调，开场即亮立场。[都市]
  例句：出来混，讲的是势力，讲的是背景。

## 网文补充（只是恋爱模拟 提炼）

> 全书扫描 + 精读筛选产物，写作导向释义 + 通用化例句。

> 都市男女对白。特征：试探靠旁敲侧击、心虚靠先发制人、暧昧靠撒娇使唤和调侃称呼。写法要点：**台词+一个出卖心思的小动作**。

- **"你果然在这，叫我一顿好找。"** — 找到人时的得意宣告。[都市]
  例句：她循着声音找过去，开口就笑："你果然在这，叫我一顿好找。"
  提示：写"寻人/抓包/重逢"的开场，得意劲儿挂在话里。

- **"你不会怪我吧？"** — 心虚先发制人的试探。[通用]
  例句：她把话绕了三圈，才小心翼翼地问："你不会怪我吧？"
  提示：写"做了可能越界的事"后探口风，等对方一句"没事"才松气。

- **"你觉得他怎么样？"** — 旁敲侧击打探口风。[都市]
  例句：她话锋一转，状似闲聊："你觉得他怎么样？"
  提示：写撮合/相亲/审问的试探，配"眼睛却没挪开"更显用意。

- **"你这话什么意思？"** — 被点破要害时的装傻反问。[通用]
  例句：他脸上的笑没变，语气却冷了半度："你这话什么意思？"
  提示：写"不愿承认"的防御式反问，配表情微变收尾。

- **"帮我揉揉腿。"** — 撒娇式使唤，亲近的借口。[都市]
  例句："站了一天，腿好酸，你帮我揉揉。"她倒也不是真酸，就是想黏着他。
  提示：写"找理由腻在一起"的撒娇，嘴上理直气壮、眼里藏笑。

- **"后天我给你发地址，记得穿精神点。"** — 长辈/朋友安排见面的指令式预告。[都市]
  例句："后天我给你发地址，记得穿精神点。"她语气不容商量。
  提示：写相亲局/家长做局的预告，一句话制造主角紧张。

- **"面子是自己挣的，不是让你凑上来丢的。"** — 敲打/翻脸的爆发金句。[都市]
  例句：她气不过，一脚踢在他小腿上："面子是自己挣的，不是让你凑上来丢的！"
  提示：写受辱反击、教训人的台词，配动作收尾更有力。

- **嗯嗯啊啊地敷衍应声** — 人在心不在的应付。[都市]
  例句：他眼睛盯着屏幕，嘴里嗯嗯啊啊地应着，一个字也没听进去。
  提示：写"边忙边敷衍"的生活流细节，接"被抓包"出笑点。

- **"这都叫上老公了。"** — 用称呼点破关系进度的调侃。[通用]
  例句："一步慢，步步慢，这都叫上老公了。"他笑着打趣。
  提示：写旁观者点破关系，一句顶十句心理描写。

- **"我呸，老子本来就是这么帅。"** — 自恋式接话，厚脸皮人设。[都市]
  例句："我呸，老子本来就是这么帅。"他得意地哼着歌，推门出去了。
  提示：写痞气/自恋型男主的自夸，配动作立人设。

- **"诶诶诶，等等。"** — 拦人先声，留住脚步。[通用]
  例句："诶诶诶，等等。"他伸手拦住她，话到嘴边又咽了回去。
  提示：写"有话要说又怕人走"的挽留，接欲言又止。

- **"那好，你有钱么？"** — 直白扎心的试探，把暧昧拉回地面。[都市]
  例句：那边几乎没打顿，紧接着回："那好，你有钱么？"
  提示：写"物质/现实的试探"，一句直球出戏剧转折。

## 网文补充（让你徒步环球 提炼）

> 全书扫描 + 精读筛选产物，写作导向释义 + 通用化例句。

- **"有一说一，……"** — 弹幕/旁观者开场的客观腔，给吐槽背书。[都市]
  例句：有一说一，整个圈子谁不知道，但凡赚钱的点子，哪一个不是写在刑法里的？
  提示：放弹幕/路人评论开头，等于"不是我一个人这么看"；后接劲爆结论。

- **"好家伙，……"** — 看到离谱场面的第一声感叹，围观群众必备。[都市]
  例句：好家伙，打人也就算了，怎么还骑人家身上，太过分了啊。
  提示：放在动作描写后面，立刻分出"围观者"视角；配连珠炮追问。

- **"说啥也得……"** — 下定决心的口语强调句式，带一股犟劲。[都市]
  例句：说啥今天也得把这两个人送到派出所去，太不是东西了。
  提示：写"非要干成"的执念/愤怒，常带"今天/今天非得"；后接具体行动。

- **"太离谱了"** — 都市吐槽万能感叹，压住一切荒诞。[都市]
  例句：谁一天能让警局派车拉两次，太离谱了。
  提示：弹幕/熟人用，一句话给事件定性；可叠"真的""妈的"增强语气。

- **"抢活抢的也太厉害了"** — 同行/官方视角的抱怨，侧面夸主角勤快。[都市]
  例句：这活儿全让他一个人抢了，抢活抢的也太厉害了。
  提示：官方或同行"怨念"=主角战绩的镜像；配摇头、苦笑。

- **"你搁这儿……呢？"** — 方言吐槽句式，质疑对方在做离谱事。[都市]
  例句：你搁这儿进货呢？一天抓仨，真当这是批发市场啊？
  提示："搁这儿/搁小卖部"是北方口语，带亲近的损；别通篇用，一句顶一片。

- **"真的，哥，不行咱退赛吧？"** — 打退堂鼓式劝退，搭档/队友的卑微求饶。[都市]
  例句：真的，哥，不行咱退赛吧，这日子真没法过了。
  提示：搭档唱衰=主角要干大事的前置；"退赛/不干了"是喜剧里的反向立flag。

- **"赶紧给XX打电话！"** — 慌乱指挥句式，现场瞬间乱起来。[都市]
  例句：还愣着干什么，赶紧给派出所打电话，就说我们这儿出事了！
  提示：写事态升级的节拍器；配"众人这才反应过来掏出手机"承接。

- **"赔老子的积分，不好好去抓人，走什么啊？"** — 直播间弹幕指挥/算账句式。[都市]
  例句：赔老子的积分！不好好去抓人，走什么啊？马路对面有个贼，在那踩点半天了，上去问问！
  提示：弹幕当"云参谋"，既刷存在感又给主角递线索；"赔积分"是押注梗，自带网感。

- **"紧张的心脏病都要犯了，实在不行赶紧想办法跑吧"** — 弹幕/亲信替主角捏汗的焦虑句式。[都市]
  例句：不行了，我紧张的心脏病都要犯了，实在不行，哥你赶紧想办法跑吧。
  提示：观众比主角慌，反差出笑点；配"弹幕刷屏/粉丝捂眼"的画面。

- **丢下一句话，……** — 话说完就走（不想纠缠/放完狠话）的收尾动作。[都市]
  例句：她丢下一句话，头也不回地走出房间，留下两人面面相觑。
  提示：衔接"说完就走"的利落转场；下一句必是"留下愣神的XX"承接反应。

## 网文补充（恋爱系统富婆校花 提炼）

（都市爽文对白·碾压·打脸）

- **先扬后抑式吐槽** — 先给好评再急转直下，比直接骂有笑果。[都市]
  例句："看你戴个眼镜挺斯文老实的，没想到说话这么油嘴滑舌的。"
  提示：前半句越正经，后半句反差越大。
- **半嗔半笑的试探** — 点破对方"嘴甜是有目的"留一半。[都市]
  例句："得得得，说这么多好听的，不会想让我给你减点房租吧？"
  提示：把"你的夸奖我收到了，但你是不是有所图"揉进玩笑话。
- **熟人揭短** — 熟络关系互相拆台的画风。[都市]
  例句："你小子说话可真不会脸红，经常用这些话骗小姑娘是吧？"她笑着摇手，气势却弱了不少。
  提示：配"笑骂"语气，揭短后对方往往心虚气势变弱。
- **夸张式调侃收入** — 用"抢银行"这类联想写"钱多到离谱"。[都市]
  例句：老妈看了转账记录，直接问："怎么，抢了哪家银行？"
  提示：用夸张联想化解炫富的俗气，长辈调侃尤其好用。
- **得意式交易** — 用"叫声哥"换条件的耍赖对白。[都市]

- **"大师，我想让你帮我算下姻缘，你看要多少钱？"** — 顾客上门求算的直球句式，报需求+问价一步到位。[都市]
