# 情绪心理词库

> 内心戏/情绪描写。写法要点：**情绪要外化——先写身体反应/动作，再落台词，避免直报"他很愤怒/她很难过"。** 情绪词单章 ≤3 次。配合 scene-craft/inner-mono。
> 标签：`[通用]` / `[古风]` / `[都市]`。`⚠` = 反 AI 冲突词。

## 愤怒 · 恨

- **怒火中烧** — 愤怒在胸中翻烧 [通用]
  ⚠ 反AI：情绪词直报，优先用动作外化（手抖、青筋）。
  提示：写"强忍不发"比直接发火有张力。
- **气血翻涌** — 怒气冲顶、理智掉线 [通用]
- **青筋暴起** — 盛怒时的血管反应 [通用]
  例句：他手背上的青筋一根根暴起，声音反而轻了。
- **牙关咬紧** — 强忍怒火不出声 [通用]
  例句：他牙关咬得咯咯响，一个字没说。
- **怒极反笑** — 怒到顶点转冷笑 [通用]
  例句：他盯着那人，怒极反笑。
- **暴跳如雷** — 怒极跳起，如雷炸开 [通用]
- **越想越气** — 怒气自行翻倍的心理循环 [通用]
- **声音反而放轻** — 怒到极点压低音量，比吼更有威胁 [通用]
  例句：他盯着对方，声音反而轻了下去。"再说一遍。"
- **鼻孔张大、喘粗气** — 暴怒前的生理前兆 [通用]
  提示：写掀桌前一秒的铺垫。
- **攥拳，指甲嵌进掌心** — 憋着怒气自伤 [通用]
  ⚠ 反AI："紧握拳头"已套路化，用"指甲嵌进掌心的力道"这类细节替代。
- **恨得牙痒痒 / 咬牙切齿** — 压抑式恨 [通用]
- **血海深仇 / 恨意滔天** — 大仇 [古风]
- **想起就膈应 / 心里堵得慌** — 都市口语式厌恶 [都市]

## 【内心独白 · 情感外化写法】

- **身体反应先行** — 先写动作，再让台词带情绪 [通用]
  例句：他端着杯子的手一紧。"你说什么？"
- **独白短促化** — 长段心思拆成短问句，靠句号停顿 [通用]
  例句：她怎么知道的？什么时候知道的？完了。
- **情绪用物件外化** — 绝望不写"他绝望了"，写具体动作 [通用]
  例句：烟灰掉了一裤腿，他也没弹。
- **先身体反应、后揭原因** — 悬念式情绪入场 [通用]
  例句：他看完那条消息，脸色肉眼可见地白了。
- **不说话、转身就走** — 情绪顶点用动作收束 [通用]
- **动作戛然而止** — 情绪转折先于语言 [通用]
  例句：他握着筷子的手停在半空，眼睛慢慢红了。
- **环境物外化情绪** — 用物件状态写心情 [通用]
- **视角锚定主角** — 内心戏只写主角能感知的 [通用]

### 生气程度：不悦 · 恼火 · 恼怒 · 震怒 · 勃然大怒
- **不悦 / 恼火 / 恼怒 / 震怒 / 勃然大怒** — 同一条愤怒曲线上的五个档位，只分轻重。
- 区别：不悦＝心里不高兴、可不动声色，最轻；恼火＝生气且开始外显；恼怒＝生气发怒、压不住了；震怒＝情绪异常激动的大怒；勃然大怒＝突然变脸色、当场爆发。
- 网文用法：小事写"不悦"、中等冲突写"恼火/恼怒"、要撕破脸才用"震怒/勃然大怒"；每章"大怒级"只给一次。

### 心理不安：担忧 · 忧虑 · 焦灼 · 忐忑
- **担忧 / 忧虑 / 焦灼 / 忐忑** — 都是心里不安，按"担心对象 + 紧迫感"区分。
- 区别：担忧＝针对具体的人或事；忧虑＝偏长期沉郁、思虑重重；焦灼＝时间紧、火烧眉毛；忐忑＝等待结果时上上下下的不安。
- 网文用法：等人/等结果用"忐忑"、亲人遇险用"担忧"、长期隐患用"忧虑"、倒计时或决战前用"焦灼"。

### 心中反应类：心中一动 · 心头一紧 · 心一沉 · 心狂跳
- **心中一动 / 心头一紧 / 心一沉 / 心狂跳** — 网文"心脏反应"快捷键，情绪强度递增。
- 区别：心中一动＝念头闪过或被触动，最轻；心头一紧＝突然紧张、预感不妙；心一沉＝知道糟了、往下坠；心狂跳＝剧烈兴奋或紧张。
- 网文用法：这四个词是被写滥的"情绪转场"，必须配具体动作落地（心动配"多看了一眼"、心一沉配"指节泛白"），否则就是反AI 点名的空转情绪。

  例句：他嘴上不敢顶撞，心里却忿忿的，直把这事记了一辈子。
  提示：写"受了窝囊气"的心理；配"垂头/攥衣角"的隐忍动作。


## 无上限补强（桃仙种道 提炼）

- **心底警钟疯狂鸣响** — 对方越安抚、自己越警觉，心底警钟狂鸣的直觉警报。[通用]
  例句：她越是轻声致歉，他越不敢掉以轻心，心底反而警钟疯狂鸣响。
  提示：写主角对"太顺理成章的事"的本能戒备；警钟鸣完必接侦查行动。

- **羞的背后酥麻** — 当众被抖露秘密的羞耻感身体化：后背酥麻、脸上热意升腾。[通用]
  例句：被当着面抖搂出心事，她羞得背后一阵酥麻，脸上热意直往上升。
  提示：害羞写"后背"比只写"脸红"新鲜；配"恨不得挖坑"收尾。

- **生出魔幻感（穿越者对世界的恍惚）** — 前世记忆与现实冲撞时的不真实感，穿越者心态锚点。[通用]
  例句：他下意识想说这是迷信，可话到嘴边又反应过来——此方世界神通伟力归于自身。
  提示：写穿越者"现代常识失灵"的瞬间；是世界观宣讲的温柔入口。

- **深入宝山却空手而归（错失之憾）** — 眼看机缘宝物在眼前却拿不到的惋惜，比"好可惜"有画面。[通用]
  例句：望着灵焰近在眼前，她总有种深入宝山却空手而归的惋惜。
  提示：写错失机缘/差一步得手的憋屈；"深入宝山空手归"一句点透读者。

- **心绪反复起落，反倒平静** — 情绪反复折腾到麻木后的平静，比直接放下更有过程感。[通用]
  例句：一年半过去连面都没见着，她心情反复起落之下，反倒平静了不少。
  提示：写漫长等待的消磨；"反复起落→平静"是时间流逝的侧面写法。

- **呼吸如风箱拉拽（重伤喘息）** — 重伤者粗粝喘息、像风箱一拉一拽，写体力濒临极限。[通用]
  例句：压抑的喘气声使他呼吸如同风箱拉拽，脊背被无形大山压得挺不直。
  提示：写重伤/脱力状态；风箱比喻贴角色认知（穷苦出身/沙场）即可保留。
