# 表情神态词库

> 面部微表情与神态描写。写法要点：**表情要连动机（为什么笑/为什么皱眉），不能贴标签**——写"眼底闪过一丝狠厉"不如写"笑意只到嘴角，没到眼睛"。
> 标签：`[通用]` / `[古风]` / `[都市]`。`⚠` = 反 AI 冲突词。

## 近义词辨析（表情组）

### 眼神/看：凝视 · 注视 · 盯 · 打量 · 瞥
- **凝视 / 注视 / 盯 / 打量 / 瞥** — 都是"看"，差别在视线停留的时间和用意。
- 区别：凝视＝长时间聚精会神地看，带神情；注视＝集中注意力看，可含侧面/暗中观察；盯＝视线死死咬住，含警惕/威慑；打量＝从头到脚审视，带评判；瞥＝迅速扫过的一眼，最不经心。
- 网文用法：主角遇敌用"盯"、发现异常用"瞥"、感情戏用"凝视"、新角色登场用"打量"；同一次对视只用一个词。

### 笑：微笑 · 轻笑 · 嗤笑 · 冷笑 · 苦笑
- **微笑 / 轻笑 / 嗤笑 / 冷笑 / 苦笑** — 都是不出声或小声的笑，差别在情绪性质。
- 区别：微笑＝中性友好、最万能；轻笑＝带响，多一分亲昵；嗤笑＝鼻子"嗤"声的轻蔑；冷笑＝含轻蔑/讥诮/怒意，反派标配；苦笑＝痛苦而勉强，多接挫败无奈。
- 网文用法：一个角色固定一个偏好笑法（反派"冷笑"、正派"微笑"、受辱硬撑"苦笑"），别一章换三种；冷门笑词（哂笑/讪笑/干笑）一次顶多一个。

### 哭：啜泣 · 呜咽 · 抽泣 · 哽咽 · 嚎啕大哭
- **啜泣 / 呜咽 / 抽泣 / 哽咽 / 嚎啕大哭** — 都是哭，按声音大小与克制程度分档。
- 区别：啜泣＝细声抽搭、压在嗓子里；呜咽＝低声带闷响；抽泣＝一吸一顿、更伤更急；哽咽＝声气阻塞、话卡在喉咙；嚎啕大哭＝放声大哭、全无压抑。
- 网文用法：隐忍戏用"哽咽"、深夜独处用"啜泣/呜咽"、失去至亲用"嚎啕大哭"；同一场景别连用两个同档哭法。

## 网文补充（玄鉴仙族 提炼）

> 全书扫描 + 精读筛选产物，写作导向释义 + 通用化例句。

- **神色凝重** — 郑重严肃的表情，出大事的标准脸。[通用]
  例句：他饮了口茶，神色凝重地望着几人。
  提示：写"宣布坏消息/摊牌前"的脸色，比"严肃"具体。

- **神色复杂** — 内心五味杂陈的反应，留白给读者猜。[通用]
  例句：对方的话出乎他意料，他低低"啊"了一声，神色复杂地望着那人。
  提示：写"复杂"时最好配一个具体小动作（低啊/偏头）。

- **面色难看** — 明显挂相的不悦/受挫。[通用]
  例句：他面色难看，明眼人都看出他落了下风。
  提示：写"下不来台/吃了亏"时的脸。

- **一言不发** — 沉默不语，情绪压到最低点。[通用]
  例句：他进了屋，一言不发，望着天窗发呆。
  提示：写"暴怒前的沉默/悲伤到失语"，比"沉默"有张力。

- **挑眉** — 挑眉＝起疑/挑衅/玩味，万能微表情。[通用]
  例句：他挑了挑眉，上下打量对方："就凭你？"
  提示：写挑衅、起疑、评估对手时的第一反应。

- **面如死灰** — 绝望/受创后的脸色，一切落空的表情。[通用]
  例句：听到功法上限锁死，他面如死灰，半晌没吭声。
  提示：写"希望破灭"的瞬间，别整段都在面如死灰。

- **神色阴晴不定** — 权衡利弊、拿不定主意的脸色切换。[通用]
  例句：他盯着那人，神色阴晴不定，迟迟没有开口。
  提示：写谈判、抉择、忌惮时的犹豫画面。

- **眼中精光一闪** — 算计/杀意/动心一闪而过的眼神。[通用]
  ⚠ 反AI：命中"眼中闪过……"句式，别整章多用；可改"他眼皮一抬，眼底的光一闪即没"。
  提示：写老狐狸动心思、杀手起杀意的瞬间。

- **阴郁地望了一眼** — 阴沉心绪外化的目光，写压抑型角色。[通用]
  例句：他阴郁地望了望窗外，没再多说。
  提示：写"话没说完就走/心事沉沉"的收尾动作。

  例句：他一脸愕然地看着那面纹丝不动的墙——这一拳居然没打碎。
  提示：写"计划落空 / 自信被打脸"；配"张了张嘴"承接。

- **笑吟吟 / 笑眯眯（笑里藏刀）** — 表面和气的笑，适合写"腹黑 / 笑面虎"。[通用]
  例句：他笑吟吟地看着对方，语气却冷得像冰。
  提示：写"笑面虎 / 扮猪吃虎"；笑 = 伪装，语言/眼神 = 真相。
  ⚠ 反AI：与"皮笑肉不笑"区分开，一场用一种。

- **冷冷一笑 / 冷哼一声** — 轻蔑的收尾反应，写"不屑跟你多说"。[通用]
  例句：他冷冷一笑："就凭你？"
  提示：写"反派轻蔑 / 主角反击前奏"；冷笑 = 下一句狠话的引子。
