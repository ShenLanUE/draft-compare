Agent 模型（跟随 Agent，Trae 式）
每个子 Agent 独立一次调用、可绑定不同模型；「跟随当前」用 AI 服务 tab 里的默认。规划用便宜快的、写作用文笔强的、审校用推理稳的。
自定义 Agent
自己定义写手角色：自定义系统提示词 + 模型 + 行为开关。创建后出现在 AI 写作面板任务区。
高级参数（写作温度 / 输出上限）
越高越发散，越低越稳定；AI 写作面板可快速调。
备份 / 导出
备份含：词库 / 黄金句 / 反AI规则 / 常用词句 / 角色卡 / 设定 / 前文库 / 设置。API Key 不导出，留在本机。
