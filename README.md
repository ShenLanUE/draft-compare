# draft-compare（稿定）

一款**网文写作工作台**：多草稿对比 + 定稿手写 + 反AI实时检查 + 词库/黄金句素材补全。把 2–4 份草稿并排对比，下方定稿区手写润色，全程有反AI检查、情绪素材和可选 AI 改写相助。

**默认完全离线**：对比、定稿、反AI检查、词库素材全部本地完成，不采集任何数据。仅在设置里手动开启「联网 AI」后，正文/选区才会发送给你配置的接口方。

---

## 一、两种使用方式

| 方式 | 说明 |
|---|---|
| **直接打开** | 双击 `index.html`，用 Chrome / Edge 打开即可（浏览器直接打开 HTML 文件） |
| **浏览器扩展** | 安装为 Chrome / Edge 扩展，点击工具栏图标一键打开，并支持在「侧边栏 / 小窗」间切换 |

两种方式功能一致；扩展额外提供侧边栏模式、模式切换、草稿跨模式保存。

## 二、扩展安装（Chrome / Edge 通用）

一套代码，两个浏览器都能装（MV3，Edge 为 Chromium 内核）。

1. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角「开发者模式 / 开发人员模式」。
3. 点击「加载已解压的扩展程序 / 加载解压缩的扩展」→ 选择本目录（`D:\Tools\draft-compare`）。
4. 工具栏出现「稿定」图标，点击即用。

> 分享给别人：把 `dist\稿定-v2.15.0.zip` 发给对方，解压后按同样方式加载即可。

## 三、使用流程

1. **点浏览器图标** → 右侧**侧边栏**直接展开（默认）
2. **导入草稿**（任选其一）：
   - 工具栏「导入草稿」按钮（可多选 `.md / .txt`）
   - 把文件拖进窗口任意位置
   - 「粘贴文本」按钮 → 弹窗内粘贴
3. 第 1 份自动作为**基准**（绿色「基准」徽标）；可随时点某栏「设为基准」重新指定
4. 用「模式」菜单在 **侧边栏 / 小窗** 间切换；草稿、基准、栏数自动保留

## 四、核心功能

### 对比呈现（流式阅读 + 内联高亮）
- 段落级智能对齐 + 段落内**字符级差异**，只有真正变化的字符被打上标记
- **删除** = 红底 + 删除线；**新增** = 翠绿底（虚线底边、圆角）
- 删掉的整段、新增的整段以块级红/绿显示；高度相似的段落做段内逐字 diff

### 栏数（1–4 栏）
- 工具栏 `单栏 / 双栏 / 三栏 / 四栏` 任意切换，栏数即空槽位数量
- 版本数 > 栏数时（如 4 份选双栏），版本栏头部出现**版本下拉框**，可切换该栏显示哪一份

### 视图与粒度
- **并排**：基准居左、各版本向右分栏，逐段对照
- **合并**：每个版本渲染成"基准 + 该版本差异"的合并文档，自上而下通读
- **字对比**（段内内联高亮）/ **行对比**（整行块级）

### 交互
- **同步滚动**（默认开）：滚动任一栏按比例联动其余栏；可关闭后各栏独立滚动
- **差异跳转**：`↑ / ↓` 按钮或 `Ctrl+↑ / Ctrl+↓` 逐处跳转差异，各栏联动定位
- **悬停联动**：鼠标悬停某段，其余栏对应段同步淡高亮
- **沉浸对比**：对比区右上角「最大化」按钮把对比区放大铺满全窗进行沉浸式对比，再点一次还原（与定稿区全屏同理）
- 每栏头部：**复制全文**（复制纯原文）、**设为基准**、**清空**（移除该栏版本回空槽位）、**改名**（✎）

### 其它
- **高亮差异开关**：关闭后进入「纯阅读模式」，各栏只显示纯原文，无任何标记
- **忽略 YAML 头**（默认开）：自动跳过 `.md` 的 front matter
- 统计栏实时显示「同步 / 删 / 增」字数与差异处数
- **导出差异报告**：工具栏「差异报告」把当前对比整理成删/增/改清单 md 下载
- 草稿、基准、栏数自动保存到 `localStorage`，切换模式/关闭重开都不丢

## 五、定稿助手（v2 新增）

> 对比区下方挂一个**定稿区**：手写润色正文时，工具充当"校对哨兵 + 素材台"。默认完全离线，内置词库随包分发（5MB）。

### 内置词库
- 随扩展打包：**词库 14 分类 / 6600+ 条** + **黄金句 8 分类 / 3900+ 句** + **反AI规则库**，首次打开自动载入
- **直接双击 `index.html` 也能完整使用**：内置词库预解析进 `js/banks-data.js`，`file://` 模式照常加载
- 词库源：27 本真实网文提炼 + 飞书《写作技巧》 + OCR 描写辞典
- 更新：`node pack.js` 时用环境变量 `BANKS_SRC` 指向最新词库目录即可自动同步

### 词句库管理（增删改查）
- 入口：底部「词库状态」栏、素材台「管理」按钮
- 四类全部可管理：**词库 / 黄金句 / 反AI规则 / 常用词句**
- 每条支持**「表单 ⇄ md 源码」双模式编辑**
- 「批量 md 编辑」：整库导出成 md 一次改完再解析保存
- 「导入 md / 导出 md」：与解析器完全往返，导出文件能再导回，方便备份/分享/自己写
- 「重置内置」：一键恢复出厂内置词库
- 界面改动即时生效：补全、反AI检查、素材台全部同步刷新
- **角色卡 / 设定卡不再放在词库管理里**：它们属于世界观设定，统一在定稿区「设定」按钮管理（见第七节）

### 格式说明
- 入口：素材台「格式说明」按钮、词库管理底部
- 讲清词句库**放在什么目录**（`banks/lexicon`、`banks/golden-sentences`、`banks/anti-ai`）、**md 写成什么格式**（含示例）、**三种维护方式**（界面改 / 写 md 导入 / 放目录重打包）

### 核心功能
1. **反AI实时检查**：打字时自动扫描，底部问题面板列出
   - T1 禁用词（仿佛/瞳孔一缩/与此同时…）红标；T2 同段聚集橙标；T3 全文密度
   - 词库 ⚠ 频率规则（攥衣角单章≤2 次、眼X≤2 次、嘴角≤3…）
   - 结构化句式（不是A而是B / 令人… / 心中涌起 / 升华句式…）
   - 点击问题 → 跳到对应位置（自动选中）
2. **情绪素材点选**：选当前情绪（默认紧张），点「补全」按钮 / `Ctrl+Enter` 或素材台浏览
   - 该情绪下的小动作/小神态/词汇候选，点选插入光标
3. **@ 全局搜索**：输入 `@` 弹出词库搜索（如 `@咽口水`），↑↓ 选择、Enter 插入、Esc/点外部关闭
4. **自动补全（可选）**：定稿区头部或设置里打开「自动补全」开关后，输入到句尾标点（。！？）或停顿 1.2 秒自动弹当前情绪候选
5. **换一种说法**：选中文字 → 点「换说法」（或 `Ctrl+Shift+Enter`）→ 替换候选
6. **黄金句对照**：素材台「黄金句」页，带"好在哪里/怎么用"，可**复制原句**（不自动插入）
7. **常用词句**：自己的高频词句池，参与 @ 搜索/素材台/补全，可导入导出 txt（词库管理里支持内联文本编辑 + 逐条删除）
8. **送对比**：把定稿一键复制进对比区空槽位，与 AI 草稿并排复核
9. **T1 一键替换**：反AI检查里禁用词直接给「替换」按钮（换成词库推荐的替代表达），可撤销
10. **设置项增强**：定稿区字号可调；Alt+P/E/R 快捷键可开关；定稿区/素材台/反AI/问题面板折叠状态自动记忆
11. **备份与导出**：设置里「导出全部备份 zip」（词库/黄金句/反AI/常用/角色卡/设定/前文库/设置，不含 API Key）；「导出差异报告」把当前对比差异整理成 md 下载

## 六、可选联网 AI 深度辅助（多子 Agent 架构）

> 默认关闭；设置里配置 API 后，AI 会**自主检索词句库再写作**，本地词库仍为主。

### 主 Agent + 多子 Agent 架构
```
主 Agent（编排 orchestrator）——决定流程、处理重试
├── 规划子 Agent (planner)     LLM：任务+上下文+情绪 → 检索关键词 + 写作要点
├── 检索子 Agent (searcher)    本地：词库/前文/角色设定检索
├── 素材整理子 Agent (material) 去重/排序；本地 / LLM 辅助两种模式
├── 写作子 Agent (writer)      LLM：结合素材/设定/前文自主选材出稿（流式）
└── 审校子 Agent (reviewer)    LLM（默认关）：复核出稿，去AI味/连贯/设定一致
```
- **四个内置任务**：润色当前句 / 续写下一段 / 扩写当前段 / 重写全段（AI 写作面板按钮）
- **每个子 Agent 独立一次 LLM 调用、模型跟随 Agent**（Trae 式）：规划用便宜快的、写作用文笔强的、审校用推理稳的
- **素材整理**：`本地` = 去重 + 预算截断（零成本）；`LLM 辅助` = 把候选素材 + 上下文 + 情绪交给 AI 精选排序
- **审校**：默认关，开 = 每次任务多一次调用，复核去 AI 味/连贯/与设定一致

### 模型跟随 Agent（统一分组选择器）
- 设置「写作 Agent」tab 里可给 规划 / 素材整理 / 写作 / 审校 分别绑定 `Provider·Model`；未绑定 = 跟随当前默认
- 所有模型下拉用**统一分组选择器**：按 Provider 分组、文案 `Model（Provider）`
- AI 面板顶部可**快速切换默认模型**（改全局默认，已绑定的 Agent 不跟随）；标题实时显示本次写作实际用的模型

### 自定义 Agent（你新建）
- 设置「写作 Agent」tab → 「自定义 Agent」区块：＋新建 / 编辑 / 停用 / 删除
- 字段：名称、系统提示词（角色定义）、运行模式（完整管线 / 直接写）、检索素材/注入角色/注入前文、模型绑定、温度/输出上限
- 创建后自动出现在 AI 写作面板任务区，点按钮即跑对应管线

### 前文库（跨章节连续性）
- 定稿区「前文库」按钮导入前文章节（md/txt，可多选），AI 写作时按关键词+上下文相似度检索最相关的段落作「前文情节」注入，维持回调/伏笔一致；检索段数可在设置里调（默认 4，0=不检索）
- **精准检索**：前文库载入时建立段落级倒排索引，AI 只扫候选命中段，不再全量扫描无关章节
- **设定名当关键词**：上下文/选区中出现的角色名（含别名）与设定名自动并入检索词；命中设定时，其「相关角色/词条」引用名也一并并入
- **章节开关**：每章可停用/恢复「参与检索」；AI 面板展示前文命中章节与段落摘要，可一键「忽略此章」
- **钉住 / 排除**：AI 面板可「📌钉住」某段（重做后强制注入）或「排除」某段（不再返回），持久生效
- **段落级搜索 + 定位**：前文库搜索按段落命中并 `<mark>` 高亮，点「定位」跳到编辑弹窗对应段并选中

### 面板体验
- **快捷键可自定义**：设置「快捷键」tab 可改绑 补全(Ctrl+Enter) / 换说法(Ctrl+Shift+Enter) / AI 润色/扩写/重写(Alt+P/E/R) / 快捷键面板(?) / 差异跳转(Ctrl+↑/↓)，支持禁用与恢复默认，即时生效；`?` 弹出速查表
- **选区即入口**：在定稿区选中文字自动弹出浮动工具条「润色 / 扩写 / 重写 / 换说法」，点按即跑；AI 快捷键可整体关闭
- **浮动结果卡**：选区触发的 AI 结果以可拖动小窗贴在选区旁流式输出，每版支持 替换/插入/复制/重做/删除；「详情」进面板看素材/前文/日志；Esc 取消
- **目标常驻**：AI 面板顶部始终显示本次「目标选区/光标句段」，不再看不到要润色的内容
- **注入透明**：展示本次实际注入的角色卡/设定名单与命中前文章节，看得见 AI 依据
- **关键词重跑**：结果区「本次关键词」chips 可删改，按这些词一键重跑（或手动填关键词跳过自动规划）
- **AI 写作**是定稿区里的标签页：流式输出 + 历史记录（最近 20 次，刷新不丢）+ 检索日志折叠
- ⚠ 反AI 词条强制要求改写后再用；面板展示检索日志（搜了什么/命中几条）与"本次用词"

### Provider 与模型
- 内置 DeepSeek / OpenAI / Anthropic / 通义千问 / 智谱 GLM / Kimi / OpenRouter / 硅基流动 / Ollama / LM Studio / Groq / 火山方舟 12 家预设，一键添加；也可新建自定义 Provider（OpenAI 兼容 / Anthropic 两种接口类型），支持改名 / 复制 / 删除 / 设为默认
- 每个 Provider 独立保存 Base URL / **模型列表（多模型可切换）** / 备注·擅长 / API Key / 流式开关；改动点「保存」才生效
- **默认模型按 Provider 记忆**：给不同 Provider 各自记住默认模型，切 Provider 不串台
- 「拉取」按钮直接从当前 API 拉模型列表（在默认模型旁边，拉完填进列表）
- **显示极简**：Provider 下拉/管理只显示提供商名字，API 地址进悬停提示，模型选择显示 `模型（提供商）`
- **AI 任务路由已废弃**：改为按子 Agent 绑定模型
- API Key 仅存本地 IndexedDB；模型列表只存 `provider.models` 一份（换 Base 不会旧列表串台）

### 合并导入
- 顶部「导入」按钮统一导入草稿和词库，按内容**自动识别**归位（词库进 IndexedDB，草稿进对比区）
- 无词库时下方状态栏提示"未载入词库"

## 七、设定管理（角色卡 + 世界观设定卡）

- 入口：定稿区 dock 头部「设定」按钮
- 独立弹窗，按分类组织设定卡：**角色** / 地点 / 门派 / 势力 / 组织 / 物品 / 功法 / 法术 / 灵兽 / 种族 / 事件 / 历史 / 风俗 / 制度 / 其他
- 支持表单 / md 双模式编辑、导入/导出 md、批量 md 编辑、搜索、删除
- **分类专属表单**：13 个分类各有定制字段（地点/门派/势力/组织/物品/功法/法术/灵兽/种族/事件/历史/风俗/制度），主描述统一为「描述」键、旧数据原样兼容；公共尾部 = 相关角色/词条 · 规则/禁忌 · 备注
- **自定义字段**：分类级（「分类」管理里给分类加模板字段，该分类新建条目自动带）+ 条目级（表单「＋ 添加自定义字段」）；md 往返无损（未知标签自动存 `extra`）
- **分类可管理**：新增/改名/删除/排序分类（改名可同步该分类下条目），分类 tab 显示条目数徽标
- **全局搜索**：「全库」开关跨角色+设定搜索，命中 `<mark>` 高亮、带分类徽标、点击跳转
- **导入去重**：导入 md 同名条目可「跳过 / 覆盖 / 存副本」；列表行支持「复制」建副本
- **相关角色/词条（related）为检索选择器**：可搜索其他角色卡（含别名）、**全部分类的设定卡**，勾选「含词库」后还纳入词句库词汇；chips 支持删除、跳转打开该卡、自定义词条；未匹配到现有条目的 chip 会灰色警示
- **角色卡 relationships / aliases 也是 chips**：关系可搜角色卡引用，别名为自由输入；双向互引
- **反向引用视图**：编辑任意卡时顶部显示「被 N 条引用：A、B、C」；删除被引用条目时有引用清单提示
- **AI 注入按相关度选卡**：按上下文/关键词相关度挑选角色卡与设定注入（覆盖全部文本字段含自定义字段），无匹配时回退全量
- **角色卡 / 设定卡会被 AI 深度辅助写作时注入**：外貌/性格/称呼/关系/当前状态/专有名词须与卡一致
- 数据存 IndexedDB 的 `character` / `setting` 表，随 md 自动识别导入；格式见「格式说明」

## 七·五、大纲 / 阅读工作区

- 顶部工具栏「对比 | 大纲」切换工作区；大纲模式下隐藏对比控件，下方定稿区保留（边读边记）
- 导入 md/txt（可多选）/ 新建 / 编辑 / 删除文档，数据存 IndexedDB `docs` 表，重开不丢
- **大纲树视图**：`#~######` 标题建可折叠树（缩进分级、显示子节数），折叠 / 展开全部
- **全文阅读视图**：标题 / 列表 / 引用 / 代码块 / 表格 / 分隔线 / 行内加粗斜体代码删除线；链接只显示文字、图片不嵌入（防 XSS / 外链）
- **搜索**：按标题 + 正文过滤并定位；命中高亮
- **导出 / 复制**：当前文档 md 源码下载 / 复制
- **写作联动**：大纲某节「送定稿」（正文送入定稿编辑器光标处）；「加前文库」（整个文档作为前文章节供 AI 检索）

## 八、模式说明（扩展）

| 模式 | 特点 |
|---|---|
| **侧边栏**（默认） | 浏览器右侧窄窗展开；全屏浏览器下可手动拉宽，够用 |

## 十、说明与隐私

- **默认完全离线**：对比 + 定稿 + 反AI检查 + 词库素材全部本地完成，不采集任何数据
- **可选联网**：仅当你在设置里主动开启「联网 AI」并配置 API Key 时，正文/选区才会发送给你指定的接口方（OpenAI 兼容 / Anthropic）
- 需要的扩展权限共四项：`clipboardWrite`（复制全文）、`sidePanel`（侧边栏）、`windows`（小窗）、`host_permissions <all_urls>`（联网 AI 访问你自定的 API 地址；不开 AI 时用不到）
- API Key 仅保存在本地浏览器 IndexedDB，不上传、不采集
- 修改代码后重新分享：先运行 `node pack.js` 重新生成 zip（自动重新构建内置词库数据、包含最新文件）；**扩展已加载时改完代码要回 `chrome://extensions` 点「重新加载」，侧边栏也重新打开**
- 词库更新：`node pack.js`（或 `$env:BANKS_SRC=...; node pack.js` 指向最新词库源目录，会自动重建 `js/banks-data.js`）
